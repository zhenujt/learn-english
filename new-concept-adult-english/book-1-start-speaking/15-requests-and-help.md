# 15 Requests and Help
## Goal and Core Formula
Ask politely with `Can/Could you + verb?` and `Could you please + verb?`.
## Examples
`Can you help me?` `Could you please check the error message?`
## Common Mistakes
`Could you to help me?` -> `Could you help me?`
## Practice and Answers
“你能再说一遍吗？” Answer: `Could you say that again?`
