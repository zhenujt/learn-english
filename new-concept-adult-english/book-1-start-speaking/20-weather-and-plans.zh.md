# 20 天气与安排：因为天气而改变计划

## 本课能做什么
能谈天气，并说明天气如何影响计划。

## 核心公式
天气主语通常用 `it`：`It is sunny.` `It is raining.` 连接原因用 `because`：`We will stay inside because it is raining.`

## 递进例句
1. `It is cold today.` 2. `It is raining, so I have an umbrella.` 3. `We are going to work from home because the weather is bad.`

## 常见错误
`Is raining` -> `It is raining.` `Because it rains, so ...` -> 只用 `because` 或 `so`。

## 口语与写作任务
描述今天的天气和衣着。写一条因天气调整约见的消息。

## 自测与答案
1. “明天会很热。”：`It will be hot tomorrow.` 2. 填空：`It ___ raining now.` 答案：`is`。
