# 04 我每天做什么：一般现在时与日程

## 本课能做什么

学完后，你能描述日常生活、工作职责和固定安排；也能问别人通常做什么。你将第一次准确区分“习惯”与“正在发生”。

## 先会说：最小可用句

`I start work at nine. She checks the dashboard every morning.`

## 发音与节奏

- 第三人称单数 `works`, `checks`, `starts` 的词尾要轻读出来，但不必夸张。
- 时间短语常连读：`at nine`、`every morning`。重读动作词和时间词：`I START WORK at NINE.`

## 核心词

`start` 开始，`finish` 结束，`check` 检查，`reply` 回复，`join` 参加，`usually` 通常，`often` 经常，`sometimes` 有时，`every day` 每天，`at` 在某时刻。

## 语法焦点：一般现在时

### 定义

一般现在时表示习惯、重复行为、日程、长期事实和职责。它通常不表示“此刻正在做”。`I work every day` 是习惯；`I am working now` 是正在发生，后面课程会专门学习。

### 核心公式

`I/You/We/They + 动词原形 + 时间`  
`He/She/It + 动词-s/es + 时间`  
`Do/Does + 主语 + 动词原形 ...?`  
`主语 + do/does not + 动词原形 ...`

拼写提示：大多数动词加 `-s`：`work -> works`；以 `-ch/-sh/-s/-x/-o` 结尾常加 `-es`：`watch -> watches`；辅音字母加 `y`，变 `y` 为 `ies`：`reply -> replies`。

## 递进例句

1. 生活口语：`I usually eat breakfast at home.`
2. 工作沟通：`Our team checks new tickets every morning, and my manager replies to urgent messages quickly.`
3. 正式说明：`The monitoring system records service activity every minute and sends an alert when an error occurs.`

## 原创对话：一天的工作

**A:** What time do you start work?  
**B:** I usually start at nine.  
**A:** Do you check messages first?  
**B:** Yes. I check email and the project board.  
**A:** What does your team do in the afternoon?  
**B:** We test new features and join a short meeting.

## 工作场景：描述职责

`I test mobile apps.`  
`She manages the project board.`  
`The service sends a report every day.`

职责说明常用一般现在时，因为它是稳定、反复发生的工作，而不是只发生一次的动作。

## 常见错误：对比记忆

| 错误 | 正确 | 原因 |
|---|---|---|
| `She check email every day.` | `She checks email every day.` | `she` 是第三人称单数。 |
| `Does he works here?` | `Does he work here?` | `does` 已带第三人称，后面动词回原形。 |
| `I am usually start at nine.` | `I usually start at nine.` | 普通动作不用 `am`。 |
| `He don't reply.` | `He doesn't reply.` | `he/she/it` 用 `doesn't`。 |

## 听读任务

听自己朗读下面一组句子，重点听 `s`：`I check the board.` / `She checks the board.` / `They check the board.` 每句读三遍。

## 口语任务

用 6 句介绍你的普通工作日。必须有：起床时间、开始工作时间、一个固定工作动作、午休、下班时间、晚间安排。再加一句描述同事或家人的日程。

## 写作任务

写一段 60--80 词英文“我的普通工作日”。至少使用三个频率词（如 `usually`, `often`, `sometimes`）和一个第三人称单数句。

## 自测

1. 填空：`My colleague ___ (start) work at 8:30.`
2. 填空：`We ___ (not check) production on weekends.`
3. 改为疑问：`She joins the daily meeting.`
4. 改错：`Does your manager replies quickly?`
5. 翻译：系统每天晚上发送一份报告。
6. 写两句：一句描述你的习惯，一句描述同事的习惯。

## 答案与自查

1. `starts`。2. `do not / don't check`。3. `Does she join the daily meeting?` 4. `Does your manager reply quickly?` 5. `The system sends a report every evening.` 6. 核心检查：`I` 后用原形；`he/she/it` 后通常加 `-s/-es`；`does` 后用原形。

## 课后复习卡

`I usually ...`；`She ...s`；`Do you ...?`；`Does he ...?`；`I don't ...`；`She doesn't ...`。
