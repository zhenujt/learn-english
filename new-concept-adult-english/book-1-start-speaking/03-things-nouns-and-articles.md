# 03 What This Is: Things, Nouns, and Articles

## Goal

Name nearby things, ask what something is, state a quantity, and make a simple request for an item or file.

## Minimum Useful Sentence

`This is a laptop. That is my phone. These are files.`

## Core Vocabulary

`laptop`, `phone`, `keyboard`, `file`, `link`, `document`, `ticket`, `screen`, `problem`.

## Grammar: Nouns, Articles, and Demonstratives

### Core Formula

`This/That is + a/an + singular noun`  
`These/Those are + plural noun`  
`I need + a/an + singular noun`  
`I need + number + plural noun`

Use `a/an` for one non-specific countable item. Use `an` before a vowel sound: `an email`, `an API`. Use `the` when both speakers know the item.

## Progressive Examples

1. `This is my key. Those are my bags.`
2. `I need a new keyboard and two monitors.`
3. `The document contains an overview and three examples of common errors.`

## Dialogue

**A:** Is this the new document?  
**B:** No, it isn't. That is the new document.  
**A:** Are these the test files?  
**B:** Yes, they are. Please open the first file.

## Common Mistakes

`This are my files` -> `These are my files`.  
`I need laptop` -> `I need a laptop`.  
`two monitor` -> `two monitors`.

## Self-check and Answers

1. `___ is an email from my manager.` Answer: `This` or `That`.  
2. `a / an API` Answer: `an API`.  
3. `I need two new monitor.` Answer: `I need two new monitors.`
