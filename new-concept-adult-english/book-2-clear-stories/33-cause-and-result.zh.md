# 33 原因与结果：为什么会这样
## 本课能做什么
能说明简单原因、结果与影响。
## 核心公式
`because + 原因`；`so + 结果`；`therefore` 用于较正式结果句。
## 递进例句
1. `I stayed home because it rained.` 2. `The test failed, so we stopped the release.` 3. `The configuration was incorrect; therefore, the service could not start.`
## 常见错误
不说 `Because ..., so ...`；选一个连接词。
## 口语与写作任务
解释一个迟到或延迟原因；写 60 词问题影响说明。
## 自测与答案
“因为网络慢，我们无法上传。”：`We could not upload because the network was slow.`
