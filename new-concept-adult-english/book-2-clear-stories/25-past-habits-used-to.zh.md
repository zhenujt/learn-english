# 25 过去习惯：以前常常怎样
## 本课能做什么
能区分过去习惯与现在状态，讲个人或团队的变化。
## 核心公式
`used to + 动词原形` 表过去常做、现在通常不做：`I used to work late.`
## 递进例句
1. `I used to live near my office.` 2. `We used to use paper forms.` 3. `The team used to test manually, but it now uses automated checks.`
## 常见错误
`used to working` -> `used to work`。`I use to` -> `I used to`。
## 口语与写作任务
比较你五年前与现在的一项习惯；写 50 词描述工作流程的变化。
## 自测与答案
“我以前不喜欢早起。”：`I didn't use to like getting up early.`
