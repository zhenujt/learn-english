# 42 描述产品：它能做什么
## 本课能做什么
能介绍一个产品或功能、目标用户和基本优点。
## 核心公式
`It is designed to + 动词`；`It helps users + 动词`；`It is useful for + V-ing/名词`。
## 递进例句
1. `This app helps people study.` 2. `It is designed to save time.` 3. `The tool is useful for teams that need simple task tracking.`
## 常见错误
`help users to can` -> `help users + 动词`。
## 口语与写作任务
介绍一个常用应用；写 80 词功能说明。
## 自测与答案
“它帮助用户管理任务。”：`It helps users manage tasks.`
