# 41 被动语态入门：事情被怎样处理
## 本课能做什么
能强调动作承受者，理解工作通知常见表达。
## 核心公式
`be + 过去分词`：`The report is sent.`；可加 `by + 动作执行者`。
## 递进例句
1. `The door is closed.` 2. `The report was sent this morning.` 3. `The issue has been reviewed by the support team.`
## 常见错误
`The report is send` -> `The report is sent.`
## 口语与写作任务
把两句主动句改被动句；写 50 词流程通知。
## 自测与答案
`The file ___ (upload) yesterday.`：`was uploaded`。
