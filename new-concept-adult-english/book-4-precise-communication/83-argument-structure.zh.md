# 83 论证结构：主张、理由和证据
## 本课能做什么
能构建有逻辑的观点段落。
## 核心公式
`主张 + 理由 + 证据/例子 + 结论`；使用 `because`, `for example`, `therefore`。
## 递进例句
1. `Testing is important.` 2. `Testing is important because it finds errors early.` 3. `Testing should be automated because it gives fast feedback; for example, it can detect repeated failures before release.`
## 常见错误
只有观点没有证据 -> 增加具体事实或例子。
## 口语与写作任务
为一个工作建议写段落；写 150 词论证。
## 自测与答案
检查你的段落是否有主张、理由、例子、结论。
