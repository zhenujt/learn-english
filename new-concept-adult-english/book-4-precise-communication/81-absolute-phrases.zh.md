# 81 独立主格与压缩表达
## 本课能做什么
能理解正式写作中带独立逻辑主语的压缩结构。
## 核心公式
`名词 + V-ing/V-ed/形容词, 主句`；`With + 名词 + V-ed, 主句`。
## 递进例句
1. `The work finished, we left.` 2. `With the test completed, we deployed.` 3. `All factors considered, the option is reasonable.`
## 常见错误
逻辑主语不清时改用完整从句。
## 口语与写作任务
把两句原因句压缩；写 80 词正式总结。
## 自测与答案
“数据库备份完成后，我们开始迁移。”：`With the database backed up, we started the migration.`
