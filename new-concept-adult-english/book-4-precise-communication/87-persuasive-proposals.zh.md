# 87 提案写作：让决策者容易同意
## 本课能做什么
能提出问题、方案、收益、成本和请求的决定。
## 核心公式
`problem + proposal + benefit + cost + recommendation`。
## 递进例句
1. `The process is slow.` 2. `We propose a simpler workflow.` 3. `We recommend automation because it reduces repeated work while keeping the cost manageable.`
## 常见错误
只有方案没有收益或成本 -> 两者都写。
## 口语与写作任务
写 180 词小提案；录 3 分钟提案说明。
## 自测与答案
提案至少回答：问题、方案、收益、成本、决策请求。
