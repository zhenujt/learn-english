# 76 第三条件句：如果过去不同
## 本课能做什么
能复盘过去决定及其可能后果。
## 核心公式
`If + had + 过去分词, would have + 过去分词`。
## 递进例句
1. `If I had left earlier, I would have arrived on time.` 2. `If we had tested it, we would have found the error.` 3. `The outage could have been avoided if the configuration had been reviewed.`
## 常见错误
`If we would have tested` -> `If we had tested`。
## 口语与写作任务
复盘一次小失误；写 100 词经验总结。
## 自测与答案
“如果我们备份了，就不会丢数据。”：`If we had backed up the data, we would not have lost it.`
