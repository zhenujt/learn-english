# 55 不定式：要做、为了做
## 本课能做什么
能表达计划、目的和希望。
## 核心公式
`to + 动词`；`want/plan/decide to + 动词`；`to + 动词` 表目的。
## 递进例句
1. `I want to learn.` 2. `We decided to wait.` 3. `We added a test to prevent errors.`
## 常见错误
`decide going` -> `decide to go`。
## 口语与写作任务
说三个本周计划；写 50 词任务目的。
## 自测与答案
“我们计划下周发布。”：`We plan to release next week.`
