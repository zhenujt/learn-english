# 74 第三册综合复习：从句到技术沟通
## 本课能做什么
能把原因、条件、限制、风险和建议连成一段清晰说明。
## 核心公式
`主张 + because 原因 + if 条件 + however 限制 + therefore 行动`。
## 递进例句
1. `We need more tests.` 2. `We need more tests because the change is risky.` 3. `If the checks pass, we can release; however, we should monitor the service.`
## 常见错误
连接词过多但逻辑不清 -> 每句只表达一个主要关系。
## 口语与写作任务
录制 3 分钟技术说明；写 150--180 词设计或事件摘要。
## 自测与答案
自查：是否有清楚主张、证据、限制和行动？是否每个从句使用正确语序？
