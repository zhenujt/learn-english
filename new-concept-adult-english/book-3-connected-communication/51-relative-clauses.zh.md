# 51 定语从句：说明是哪一个
## 本课能做什么
能限定人、物、地点和时间。
## 核心公式
`noun + who/which/that + 句子`；`whose + 名词`；`where + 句子`。
## 递进例句
1. `The person who called is my manager.` 2. `This is the file that I need.` 3. `The service that sends emails is unavailable.`
## 常见错误
`The man which helped` -> `The man who helped.`
## 口语与写作任务
描述一位同事和一个工具；写 60 词产品说明。
## 自测与答案
“我需要昨天发送的文件。”：`I need the file that was sent yesterday.`
