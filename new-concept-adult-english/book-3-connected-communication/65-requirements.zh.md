# 65 需求说明：用户需要什么
## 本课能做什么
能陈述用户需求、限制和验收条件。
## 核心公式
`Users need to + 动词`；`The system must + 动词`；`should be able to + 动词`。
## 递进例句
1. `Users need to sign in.` 2. `The system must save the form.` 3. `Users should be able to reset a password without support.`
## 常见错误
`must to save` -> `must save`。
## 口语与写作任务
写三条功能需求；写 100 词用户故事。
## 自测与答案
“系统必须显示错误信息。”：`The system must display an error message.`
