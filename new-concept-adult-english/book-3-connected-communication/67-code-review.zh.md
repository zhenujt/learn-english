# 67 代码审查：给出建设性反馈
## 本课能做什么
能提出具体、尊重且可执行的审查意见。
## 核心公式
`Could we + 动词?`；`It might be better to + 动词`；`This could + 动词`。
## 递进例句
1. `Could we rename this?` 2. `It might be better to add a test.` 3. `This could cause an error when the value is empty.`
## 常见错误
`This is bad` -> 说明原因和建议。
## 口语与写作任务
把三条批评改建设性反馈；写 80 词 review。
## 自测与答案
“我们能加一个测试吗？”：`Could we add a test?`
