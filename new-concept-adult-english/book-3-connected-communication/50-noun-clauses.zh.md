# 50 名词性从句：把信息当作一件事
## 本课能做什么
能说明“我知道什么、问题是什么、是否可行”。
## 核心公式
`I think/know that + 句子`；`whether/if + 句子`；`what + 句子`。
## 递进例句
1. `I think that you are right.` 2. `We need to know whether it works.` 3. `What we need is a clear plan.`
## 常见错误
`I know where is it` -> `I know where it is.`
## 口语与写作任务
解释你需要确认的一件事；写 60 词澄清消息。
## 自测与答案
“我不知道文件在哪里。”：`I don't know where the file is.`
