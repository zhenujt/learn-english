# 72 文档写作：让别人能照着做
## 本课能做什么
能写清晰标题、前置条件、步骤和结果。
## 核心公式
`Before + V-ing`；祈使句；`Make sure + 句子`；`If ..., ...`。
## 递进例句
1. `Open the settings page.` 2. `Before deploying, back up the database.` 3. `Make sure that all tests pass before you continue.`
## 常见错误
文档只有动作没有条件 -> 补充前置条件和验证结果。
## 口语与写作任务
写一个五步操作指南；写 120 词 README 段落。
## 自测与答案
“继续前请确认测试通过。”：`Make sure the tests pass before you continue.`
