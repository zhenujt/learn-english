# 57 分词：压缩描述信息
## 本课能做什么
能理解并使用常见的现在分词和过去分词修饰语。
## 核心公式
`V-ing` 表主动/进行；`V-ed` 表被动/完成：`the engineer working`，`the file sent`。
## 递进例句
1. `The running water is cold.` 2. `The file sent yesterday is important.` 3. `The team working on payments needs more time.`
## 常见错误
`the file sending yesterday` -> `the file sent yesterday`。
## 口语与写作任务
用分词描述两个文件或任务；写 60 词更新。
## 自测与答案
“正在运行的服务”：`the service running now`。
