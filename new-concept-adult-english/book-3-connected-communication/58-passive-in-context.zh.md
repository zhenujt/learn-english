# 58 被动语态进阶：谁做不重要时
## 本课能做什么
能在通知、流程和报告里选择主动或被动。
## 核心公式
`be + V-ed`；时态由 `be` 决定：`was fixed`、`has been fixed`。
## 递进例句
1. `The door was closed.` 2. `The report has been sent.` 3. `Customer data is protected by several controls.`
## 常见错误
`has been send` -> `has been sent`。
## 口语与写作任务
把三句主动通知改为被动；写 70 词维护通知。
## 自测与答案
“问题已经解决。”：`The issue has been resolved.`
