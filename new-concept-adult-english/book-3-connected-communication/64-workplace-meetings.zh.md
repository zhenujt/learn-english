# 64 会议表达：提出、确认和总结
## 本课能做什么
能在会议中表达进展、提出问题和总结行动项。
## 核心公式
`I'd like to ...`；`Could we ...?`；`To summarize, ...`。
## 递进例句
1. `I'd like to ask a question.` 2. `Could we review the timeline?` 3. `To summarize, we will test today and decide tomorrow.`
## 常见错误
`I want ask` -> `I'd like to ask`。
## 口语与写作任务
录 60 秒会议发言；写行动项列表。
## 自测与答案
“总结一下……”：`To summarize, ...`
