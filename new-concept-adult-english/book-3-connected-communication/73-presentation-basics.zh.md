# 73 简短演示：清楚地讲三分钟
## 本课能做什么
能做结构化的简短演示并引导听众。
## 核心公式
`Today I'd like to ...`；`First/Next/Finally`；`The key point is ...`；`Any questions?`
## 递进例句
1. `Today I'd like to share an update.` 2. `First, I will explain the problem.` 3. `The key point is that the new flow reduces manual work.`
## 常见错误
一开始就讲细节 -> 先说目标和结构。
## 口语与写作任务
录制 3 分钟演示；写 150 词讲稿。
## 自测与答案
写一句开场：`Today I'd like to ...`
