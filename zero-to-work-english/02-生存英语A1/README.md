# 第 2 阶段 · 生存英语（A1）

> 打好发音基础后，正式进入"能开口"的阶段。这一阶段教你**最基本、最高频**的英语，让你在生活里"活下来"：打招呼、自我介绍、点餐、问路、买东西、说时间。

---

## 学完这一阶段，你能做到

- ✅ 用英语打招呼、介绍自己（姓名、职业、来自哪里）
- ✅ 说数字、时间、日期、价格
- ✅ 在餐厅点餐、在商店买东西
- ✅ 问路、听懂简单指路
- ✅ 用最基本的时态说"我是谁、我在做什么、我有什么"
- ✅ 看懂简单的英文标识、菜单、短消息

**对标水平：欧标 A1（入门级）。**

## 每一课怎么学？

按 [每日 30 分钟模板](../00-学习方法/02-制定可坚持的学习计划.md) 走，每课都包含 7 个板块：

```
🎯 本课目标 → 💬 先会说 → 🔑 核心词汇 → 📖 语法句型
→ ⚠️ 中英对比避坑 → 🎧 听说读写练习 → ✅ 自测与答案
```

**重点**：每课的"先会说"要**大声念出来、用自己的情况替换**。学英语不是读懂，是**用出来**。

从 [第 01 课：打招呼与自我介绍](01-打招呼与自我介绍.md) 开始吧！
