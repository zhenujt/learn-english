# 零基础到工作沟通：成年人英语自学方案

> 专为 **30 岁以上、零基础** 的中国成年人设计。
> 目标：学完能**看懂英文字幕、听懂日常与工作对话、开口交流、写清楚邮件和消息**，达到欧标 **B1（中级）** 水平，能在软件开发等职场环境正常沟通。

---

## 这套方案和别的有什么不同？

市面上的教材大多是给学生或年轻人设计的，节奏快、假设你有基础、脱离真实生活。这套方案针对成年人的特点重新设计：

| 成年人的特点 | 本方案的应对 |
|---|---|
| 记忆力不如年轻人，但**理解力和逻辑更强** | 先讲"为什么"，用逻辑串联知识，而不是死记硬背 |
| 时间碎片化，容易半途而废 | 每课 **20–30 分钟**可完成，有明确的每日打卡节奏 |
| 最怕**发音不准、不敢开口** | 从音标和跟读练起，先解决"张不开嘴"的心理障碍 |
| 学了就忘 | 内置**间隔复习系统**，每周有复盘，对抗遗忘曲线 |
| 需要立刻能用 | 场景全部来自**真实生活 + 软件开发职场**，学完即用 |
| 受中文思维干扰，说"中式英语" | 每个知识点都有**中英对比**，专治 Chinglish |

## 学习理念：四个核心原则

### 1. 发音是地基，先修 2 周
很多成年人学了十几年英语还是"哑巴英语"，根子在发音没打好——读不准就听不懂、不敢说。所以我们**第一阶段专攻发音**，不急着背单词。

### 2. 先会说整句，再懂语法
小孩学母语不是先学语法的。我们先让你把高频句型当"整块"记下来直接用（比如 `Can I have...?`），能开口之后，再回头理解背后的语法。**语法是用来解释和扩展的工具，不是入门的门槛。**

### 3. 大量"可理解的输入"
学语言 80% 靠"输入"（听和读），20% 靠"输出"（说和写）。我们提供大量**你能听懂看懂**的材料（配中文对照），让英语像空气一样包围你。听力允许看字幕——**先看懂字幕的意思**，这本身就是巨大的进步。

### 4. 用起来才记得住
每课都要求你**用自己的真实情况造句**（说自己的工作、自己的一天），而不是背课本里的例句。用过一次，胜过读十次。

## 完整学习路线图

整套方案分为 **6 个阶段**，建议总周期 **10–14 个月**（每天 30–45 分钟）。

```
第 0 阶段  学习方法      →  1 周    先学"怎么学"，少走弯路
第 1 阶段  发音入门      →  2–3 周  音标 + 自然拼读，敢开口
第 2 阶段  生存英语 A1   →  8–10 周 最基本的生活沟通
第 3 阶段  日常沟通 A2   →  10-12 周 流畅的日常表达
第 4 阶段  工作沟通 B1   →  12-14 周 职场邮件、会议、协作
第 5 阶段  语法精要      →  贯穿全程 系统梳理语法（随查随用）
```

## 每一课的固定结构

为了让你形成学习节奏，**每一课都包含这 7 个板块**：

1. **🎯 本课目标** — 学完你具体能做什么（一句话说清）
2. **💬 先会说** — 3–5 个当堂就能用的高频整句（先用后学）
3. **🔑 核心词汇** — 本课要掌握的单词/短语，配音标和例句
4. **📖 语法/句型讲解** — 用中文讲清"为什么"，配公式和图示
5. **⚠️ 中英对比 · 避坑** — 中国人最容易犯的错，红叉对绿勾
6. **🎧 听说读写练习** — 四项技能各有练习，听力配字幕
7. **✅ 自测与答案** — 检验学习效果，附参考答案

## 怎么用这套方案？（每日 30 分钟模板）

```
┌─ 5 分钟   复习昨天的内容（看自测题，能答上来就过）
├─ 15 分钟  学习今天的新课（读讲解 + 跟读例句）
├─ 8 分钟   做本课的听说读写练习
└─ 2 分钟   在自测题上打勾，把不会的记到"错题本"
```

**每周日**：不学新课，只复习本周 6 课的自测题和错题本。

---

## 给你的三句心里话

1. **不要追求完美。** 能沟通比语法全对重要一百倍。老外根本不在意你的时态错了没有。
2. **每天 20 分钟，胜过周末狂补 3 小时。** 语言靠的是"频率"，不是"时长"。
3. **开口会尴尬，这很正常。** 每个说得好的人都经历过说得烂的阶段。张嘴，就赢了一半。
