# 第 1 阶段 · 发音入门

> **这是整套方案最重要的地基。** 花 2–3 周把发音打好，你后面的听、说都会顺很多。
> 目标：认识 48 个国际音标，看到单词能拼读、听到读音能反应、开口不再"哑巴英语"。

---

## 为什么零基础要先学发音？

| 如果发音没打好 | 会发生什么 |
|---|---|
| 读不准单词 | 记的是"错的声音"，一听正确读音就懵 |
| 听不懂 | 你脑子里的读音和老外说的对不上 |
| 不敢开口 | 怕读错，越怕越不说，越不说越差 |
| 记单词慢 | 只能靠死记字母顺序，不能靠读音记 |

**先修发音 = 一次投入，终身受益。** 就像盖楼先打地基。

## 学习建议

1. **一定要出声。** 发音是肌肉记忆，光看不练等于没学。
2. **对着镜子看嘴型。** 英语很多音，嘴型和中文不一样。
3. **用手机录下自己的发音**，和标准音对比，你会进步很快。
4. 这个阶段**慢一点没关系**，音标是终身受用的基本功。

学完这 6 篇，你就能进入 [第 2 阶段 · 生存英语](../02-生存英语A1/) 了。
