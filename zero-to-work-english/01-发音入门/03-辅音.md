# 03 · 辅音

> 辅音是单词的"轮廓"。元音响亮，辅音清晰，两者配合单词才清楚。这一课重点练几个中文没有、中国人最容易读错的辅音。

---

## 一、辅音的两个关键概念

### 概念 1：清辅音 vs 浊辅音
很多辅音是**成对**的：嘴型完全一样，区别只在**声带振不振动**。
- **清辅音**：声带不振动，只有气流（像悄悄话）。
- **浊辅音**：声带振动，有"嗡嗡"的声音。

**自检法**：手指按住喉咙发音，**喉咙震=浊音，不震=清音**。

### 概念 2：辅音要"干脆"，别加元音
中国人最大的毛病：在辅音后面**多加一个"呃"音**。
- ❌ `book` 读成 "布-可-呃"
- ✅ `book` = /bʊk/，结尾的 /k/ 干脆收住，不要"呃"

## 二、8 对清浊辅音（成对记最高效）

| 清辅音 | 浊辅音 | 发音要领 |
|---|---|---|
| /p/ pen 笔 | /b/ bag 包 | 双唇闭紧，突然放开 |
| /t/ ten 十 | /d/ dog 狗 | 舌尖抵上齿龈，放开 |
| /k/ key 钥匙 | /g/ go 去 | 舌后抵软腭，放开 |
| /f/ fish 鱼 | /v/ van 货车 | 上齿咬下唇，吹气 |
| /s/ sun 太阳 | /z/ zoo 动物园 | 舌尖近齿龈，吹气"嘶/兹" |
| /θ/ think 想 | /ð/ this 这 | **咬舌尖**，吹气 |
| /ʃ/ she 她 | /ʒ/ vision 视觉 | 双唇微突，"嘘/日" |
| /tʃ/ chair 椅子 | /dʒ/ job 工作 | "去/知"，短促 |

### ⭐ 重点难点（中文没有，必须专练）

**/θ/ 和 /ð/（咬舌音 th）**
- 舌尖轻轻放在**上下齿之间**，然后吹气。
- /θ/ 清（不震喉）：think, three, mouth, thank
- /ð/ 浊（震喉）：this, that, they, mother
- ❌ 常见错误：读成 /s/ 或 /z/（think 读成 "sink"），或 /f/（three 读成 "free"）。
- ✅ 一定要**能看到舌尖**露出来一点点。

**/v/（咬唇音）**
- 上齿咬下唇，振动声带（浊音）。
- ❌ 常见错误：读成 /w/，`very` 读成 "weri"。
- ✅ 对比：`vet`（兽医）咬唇 vs `wet`（湿）圆唇不咬。

**/z/**
- 像蜜蜂"兹——"，声带振动。
- ❌ 常读成 /s/，`is` 读成 "iss"。
- ✅ 对比：`price`（价格）/s/ vs `prize`（奖品）/z/。

## 三、其他辅音

| 音标 | 例词 | 发音要领 |
|---|---|---|
| /m/ | man 男人 | 双唇闭合，鼻子出声 |
| /n/ | no 不 | 舌尖抵齿龈，鼻子出声 |
| /ŋ/ | sing 唱, English | 舌后抵软腭，鼻子出声（"嗯"） |
| /h/ | hat 帽子 | 轻轻哈气 |
| /l/ | leg 腿, ball 球 | 舌尖抵齿龈 |
| /r/ | red 红, room | **舌头卷起但不碰上颚**，圆唇 |
| /w/ | we 我们, water | 双唇收圆突出 |
| /j/ | yes 是, you | 舌前抬向硬腭，"耶" |

### ⭐ 重点：/l/ 的两种读法
- **词首/元音前**（清晰 l）：`light, love` —— 舌尖抵齿龈，清脆。
- **词尾**（暗 l）：`ball, feel, people` —— 舌尖同样抵齿龈，但听起来更"厚"，别丢掉它。
- ❌ 常见错误：`people` 读成 "pipo"，把结尾 /l/ 吞了。

### ⭐ 重点：/r/ 和 /l/ 别混
- `red`（红）/r/：舌头卷起、不碰上颚。
- `led`（带领）/l/：舌尖抵住齿龈。
- 中国部分地区学习者容易混，注意舌头**碰不碰上齿龈**。

## 四、常见错误总结

| ❌ 错误 | ✅ 正确 |
|---|---|
| 辅音后加"呃"（book→"布可呃"） | 结尾辅音干脆收住 |
| /θ//ð/ 读成 s/z/f（think→sink） | 咬舌尖吹气，能看到舌头 |
| /v/ 读成 /w/（very→weri） | 上齿咬下唇 |
| 词尾 /l/ 被吞（people→pipo） | 舌尖抵齿龈，读出来 |
| 清浊不分（prize→price） | 按喉咙震不震区分 |

## ✅ 本篇自测

1. 怎么快速判断一个辅音是清音还是浊音？
2. /θ/（think 的 th）怎么发？中国人常错读成什么？
3. `very` 被读成 "weri" 是哪个音发错了？正确怎么发？
4. `people` 结尾的 /l/ 为什么不能吞掉？

<details>
<summary>点击看答案</summary>

1. 手指按喉咙发音，喉咙振动=浊音，不振动=清音。
2. 舌尖放在上下齿之间吹气（清音不震喉）；常错读成 /s/（sink）或 /f/（free）。
3. /v/ 读成了 /w/；正确应上齿咬下唇、振动声带。
4. 英语词尾辅音要读出来，吞掉 /l/ 会让单词不完整、不清晰，也会影响连读和听辨。

</details>
