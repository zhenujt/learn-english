# 04 · 自然拼读规则

> 学会音标后，这一课教你**字母组合和读音的规律**。掌握它，看到陌生单词能"猜"出读音，听到读音能"拼"出大概的写法——这是英语母语孩子学阅读的核心方法。

---

## 一、什么是自然拼读（Phonics）？

**自然拼读**就是"字母（组合）→ 读音"的规律。英语约 **75% 的单词**是符合规律、可以拼读的。

- 会音标：能读**任何**词（查字典看 /  /）。
- 会拼读：能**快速猜**大部分词的读音，不用每个都查。

两者结合，你就有了独立阅读生词的能力。

---

## 二、辅音字母的读音（基本一一对应，好记）

大多数辅音字母读音就是它对应的音标，很直接：

| 字母 | 读音 | 例词 | 字母 | 读音 | 例词 |
|---|---|---|---|---|---|
| b | /b/ | bag | n | /n/ | net |
| d | /d/ | dog | p | /p/ | pen |
| f | /f/ | fish | r | /r/ | red |
| h | /h/ | hat | s | /s/ | sun |
| j | /dʒ/ | jam | t | /t/ | ten |
| k | /k/ | kite | v | /v/ | van |
| l | /l/ | leg | w | /w/ | web |
| m | /m/ | man | z | /z/ | zoo |

**两个字母有"软硬"两种读音：**

| 字母 | 硬音 | 软音（后接 e/i/y 时） |
|---|---|---|
| c | /k/：cat, cup | /s/：city, face, nice |
| g | /g/：go, big | /dʒ/：age, giant, page |

## 三、元音字母的两种读音（最重要的规律！）

5 个元音字母 **a e i o u** 各有两种主要读音：**短音**和**长音（=字母本身的名字）**。

### 规律 1：闭音节 → 读"短音"
单词是"辅音 + 元音 + 辅音"结构（元音被辅音包住），元音读**短音**：

| 字母 | 短音 | 例词 |
|---|---|---|
| a | /æ/ | cat, map, bad, hand |
| e | /e/ | bed, pen, red, ten |
| i | /ɪ/ | sit, big, pig, milk |
| o | /ɒ/ | hot, dog, box, stop |
| u | /ʌ/ | cup, bus, run, sun |

### 规律 2：元音 + 辅音 + e（哑音 e） → 读"长音"
单词结尾是"元音 + 一个辅音 + e"，**结尾的 e 不发音**，前面的元音读**长音（字母名）**：

| 结构 | 短音（无 e） | 长音（+e） |
|---|---|---|
| a_e | cap /kæp/ 帽子 | cape /keɪp/ 斗篷 |
| i_e | kit /kɪt/ 工具包 | kite /kaɪt/ 风筝 |
| o_e | hop /hɒp/ 跳 | hope /həʊp/ 希望 |
| u_e | cut /kʌt/ 切 | cute /kjuːt/ 可爱 |
| a_e | mad /mæd/ 疯 | made /meɪd/ 做（过去式） |

> 这条"哑音 e"规律超级实用！看到 `name, time, home, make, nice`，你立刻知道前面元音读长音、结尾 e 不发音。

## 五、拼读实战：把单词"拆开读"

看到生词，先拆成"字母块"，再拼起来：

```
sunshine  →  sun + shine  →  /sʌn/ + /ʃaɪn/  →  阳光
raincoat  →  rain + coat  →  /reɪn/ + /kəʊt/  →  雨衣
notebook  →  note + book  →  /nəʊt/ + /bʊk/  →  笔记本
website   →  web + site   →  /web/ + /saɪt/   →  网站（软件常用）
```

**软件开发场景练习：**
```
click    →  cl + i + ck    →  /klɪk/     点击
input    →  in + put       →  /ˈɪnpʊt/   输入
update   →  up + date      →  /ˈʌpdeɪt/  更新
online   →  on + line      →  /ˈɒnlaɪn/  在线
```

## 六、注意：英语有 25% "不规则"词

有些高频词不按规律读，只能单独记（叫"视觉词"）：

| 单词 | 读音 | 别按规律读 |
|---|---|---|
| the | /ðə/ | 不读 "特喝" |
| one | /wʌn/ | 不读 "欧内" |
| two | /tuː/ | w 不发音 |
| said | /sed/ | 不读 "赛德" |
| do | /duː/ | 不读 "斗" |

> 遇到不规则的高频词，别纠结，**单独记住它**就好。占比不高。

## ✅ 本篇自测

1. 自然拼读和音标各自的作用是什么？
2. "哑音 e"规律是什么？`kit` 和 `kite` 有什么区别？
3. 字母组合 `sh` `th` `ch` 分别读什么音？
4. `website` 怎么拆开拼读？

<details>
<summary>点击看答案</summary>

1. 音标能读任何词（查字典）；自然拼读能快速猜大部分词的读音，不用逐个查。
2. "元音 + 辅音 + e"结尾时，e 不发音，前面元音读长音（字母名）。kit /kɪt/（短音 i），kite /kaɪt/（长音 i，e 不发音）。
3. sh = /ʃ/，th = /θ/ 或 /ð/，ch = /tʃ/。
4. web + site → /web/ + /saɪt/ → website。

</details>
