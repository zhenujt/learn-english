# 第 3 阶段 · 日常沟通（A2）

> 生存英语让你"活下来"，日常沟通让你"聊起来"。这一阶段教你讲过去发生的事、说未来的计划、表达感受和意见，让英语从"应急"变成"交流"。

---

## 学完这一阶段，你能做到

- ✅ 讲述过去发生的事（昨天、上周做了什么）
- ✅ 谈论未来计划（打算做什么、周末安排）
- ✅ 表达感受、喜好和意见
- ✅ 打电话、发消息、简单闲聊
- ✅ 描述人、地点和物品
- ✅ 听懂并参与日常对话

**对标水平：欧标 A2（初级）。**

---

## 课程规划

| 课 | 主题 | 核心语法 |
|---|---|---|
| 01 | 谈论昨天做了什么 | 一般过去时（was/were、动词 -ed） |
| 02 | 不规则动词的过去式 | went / had / did / made... |
| 03 | 现在正在做什么 | 现在进行时（be + doing） |
| 04 | 谈论未来计划 | be going to / will |
| 05 | 表达喜好与感受 | like/hate + doing、形容词 |
| 06 | 打电话与发消息 | 电话用语、Can I speak to... |
| 07 | 描述人和物 | 形容词顺序、比较级 |
| 08 | 谈论经历 | 现在完成时入门（have done） |
| 09 | 提建议与做决定 | should、Let's、Why don't we |
| 10 | 讲一个小故事 | 时态综合运用 |

---

## 学习提示

这一阶段的核心是**掌握时态**——英语靠动词变化来表达"什么时候发生"。别怕，我们会用大量生活例子，配中英对比，把每个时态讲透。
