# 第 5 阶段 · 语法精要（随查随用）

> 前面 4 个阶段是"跟着学"，这一阶段是"随时查"。当你在学习或工作中遇到某个语法搞不清（时态？从句？介词？），到这里查对应的知识点。
> 语法是**工具**，不是门槛——遇到问题再查，比一开始死磕语法书高效得多。

---

## 怎么用这个语法库？

- **不用从头到尾读。** 遇到具体问题时，查对应条目即可。
- 每个语法点都包含：**核心公式 + 常见错误对比 + 3 个递进例句 + 小测验**。
- 按"基础 → 进阶 → 高级"三档组织，配合你的学习阶段查阅。

---

## 一、基础篇（配合第 2–3 阶段）

| 语法点 | 一句话说清 |
|---|---|
| 名词：可数与不可数 | 能数的用 a/复数，不能数的用 some |
| 冠词 a / an / the | a/an 表"一个"，the 表"特指" |
| 代词 I/me/my/mine | 主格/宾格/物主，别用错 |
| be 动词 am/is/are | "是"，随主语变 |
| 一般现在时 | 表习惯、事实；第三人称单数加 -s |
| 一般过去时 | 表过去；动词 -ed 或不规则变化 |
| 现在进行时 | be + doing，表正在进行 |
| 一般将来时 | will / be going to |
| 五大基本句型 | 主谓、主谓宾、主系表… |
| 形容词与副词 | 描述名词 vs 描述动词 |
| 介词 in/on/at | 时间和地点的"点线面" |
| 疑问句与否定句 | 助动词 do/does/did 的用法 |

## 二、进阶篇（配合第 4 阶段）

| 语法点 | 一句话说清 |
|---|---|
| 现在完成时 | have done，连接过去与现在 |
| 过去进行时 | 过去某刻正在做 |
| 比较级与最高级 | -er/more、-est/most |
| 情态动词 | can/could/should/must/may |
| 被动语态 | be + done，"被…" |
| 名词性从句 | that/what/whether 引导的从句 |
| 定语从句 | who/which/that 修饰名词 |
| 状语从句 | when/because/if/although… |
| 非谓语动词 | to do / doing / done |
| 直接与间接引语 | 转述别人的话 |

## 三、高级篇（提升到 B2+）

| 语法点 | 一句话说清 |
|---|---|
| 虚拟语气 | 表假设、非真实（If I were you…） |
| 倒装句 | 强调时语序颠倒 |
| 强调句型 | It is... that... |
| 省略 | 避免重复的省略 |
| 独立主格结构 | 附加说明的紧凑表达 |
| 各种时态综合 | 时态在真实语境中的配合 |

## 给你的建议

**不要因为语法而焦虑。** 母语者也说不清很多语法规则，但照样说得流利。语法的作用是：
1. 当你**说错被纠正**时，帮你理解"为什么错"。
2. 当你想表达**更复杂的意思**时，给你更多"句子模板"。

**先能沟通，再求精确。** 这才是成年人学英语的正确顺序。
