# 第 4 阶段 · 工作沟通（B1）

> 这是你的**终极目标阶段**：在职场（尤其是软件开发环境）用英语沟通。写邮件、开会、汇报进度、参与技术讨论、和同事协作——学完这一阶段，你就能在国际化的工作环境里立足。

---

## 学完这一阶段，你能做到

- ✅ 写清楚、专业的英文邮件（请求、汇报、道歉、跟进）
- ✅ 在会议上发言：表达观点、同意/反对、提问
- ✅ 汇报工作进度、描述问题、给出方案
- ✅ 参与技术讨论（需求、bug、代码评审、部署）
- ✅ 与同事日常协作沟通（Slack/Teams 消息、站会）
- ✅ 听懂英文会议和技术分享（可配字幕）

**对标水平：欧标 B1（中级）——能在工作场景独立沟通。**

## 软件开发常用表达抢先看

```
I'll pick up this task.              我来接这个任务。
Let me sync with you later.          我待会儿和你对一下。
The build is failing.                构建失败了。
I pushed my changes.                 我推送了我的改动。
Can you review my PR?                你能评审下我的 PR 吗？
Let's circle back on this tomorrow.  这个我们明天再议。
LGTM (Looks good to me).             我看没问题（评审通过）。
```

> 这些是真实工作中天天用的表达，本阶段会逐一详细讲解、配场景对话。

## 学习提示

这一阶段最重要的是**场景化**和**礼貌得体**。英语职场沟通讲究"委婉而清晰"——既要说明白，又不能太生硬。每课都会重点讲"怎么说才专业、才礼貌"，并大量使用软件开发的真实场景。
