# 14 天软件会议与 Demo 生存训练

> 面向需要尽快参加英文会议、演示软件功能的零基础学习者。先把高频表达作为完整句块使用，再到《软件职场英语语法全解》中理解规则。

[English version](software-meeting-demo-14-day.md) · [语法全解](software-workplace-grammar-guide.zh.md) · [场景表达手册](software-workplace-phrases.zh.md)

## 使用方法

每天训练 20–30 分钟：

1. 播放顶部完整音频：每个中文提示 1 遍，Jenny 英文 3 遍。
2. 点击例句旁的播放按钮，单独练习需要加强的英文句子。
3. 替换方括号中的内容，至少说出 3 个新句子。
4. 完成当天任务并录音，不因一个错误中断表达。
5. 能在 3 秒内开始说、完成整段任务，才进入下一天。

## Day 1：进入会议并确认设备

```text
Hi everyone. Thanks for joining.
大家好，感谢参加会议。

Can everyone hear me clearly?
大家能听清我的声音吗？

Can everyone see my screen?
大家能看到我的屏幕吗？

Let me share my screen.
我来共享屏幕。

Shall we get started?
我们开始吧？

I will keep this brief.
我会尽量简短。
```

替换练习：把 screen 换成 slides 或 browser。

今日任务：完成一次 20 秒会议开场，包括问候、声音、屏幕和开始会议。

## Day 2：没听清和没听懂

```text
Could you say that again, please?
可以再说一遍吗？

Could you speak a little more slowly?
可以说慢一点吗？

I did not catch the last part.
我没有听清最后一部分。

Could you rephrase the question?
可以换一种方式问这个问题吗？

Could you give me an example?
可以举个例子吗？

Let me make sure I understood correctly.
我确认一下自己是否理解正确。
```

替换练习：把 last part 换成 question、number 或 requirement。

今日任务：不看英文，连续说出 3 种请求对方解释的方法。

## Day 3：介绍页面和目标

```text
Today, I will show the main user flow.
今天我会演示主要用户流程。

This is the user management page.
这是用户管理页面。

The goal is to make this process faster.
目标是让这个流程更快。

This feature helps users manage their accounts.
这个功能帮助用户管理账号。

I am using a test account with sample data.
我使用的是带示例数据的测试账号。

This is the latest build from the test environment.
这是测试环境中的最新版本。
```

替换练习：把 user management page 换成你真实演示的页面名称。

今日任务：用 30 秒介绍真实页面、演示目标和测试环境。

## Day 4：描述操作和结果

```text
I click this button.
我点击这个按钮。

The dialog opens.
弹框打开了。

I enter a keyword in this field.
我在这个输入框中输入关键词。

The matching results appear below.
匹配结果显示在下方。

I select an option from the list.
我从列表中选择一个选项。

The page updates automatically.
页面会自动更新。
```

替换练习：依次替换 button、field、option 和 page。

今日任务：打开一个真实页面，边操作边说出至少 6 个短句。

## Day 5：按顺序完成一个流程

```text
First, I open the filter menu.
首先，我打开筛选菜单。

Next, I select Active.
接下来，我选择 Active。

Then, I apply the filter.
然后，我应用筛选条件。

Now, the table shows only active users.
现在，表格只显示活跃用户。

Finally, I clear the filter.
最后，我清除筛选条件。

That completes the workflow.
这个流程就完成了。
```

替换练习：用自己产品里的 4 个操作替换筛选流程。

今日任务：使用 First、Next、Then、Finally 完成 45 秒演示。

## Day 6：说明价值和限制

```text
This saves users time.
这可以节省用户的时间。

This reduces the number of manual steps.
这减少了手动操作步骤。

The main benefit is faster feedback.
主要好处是反馈更快。

At the moment, this supports one option at a time.
目前，这一次只支持一个选项。

This is not included in the current scope.
这不在当前范围内。

We plan to support this in a future release.
我们计划在后续版本中支持它。
```

替换练习：把 faster feedback 换成真实价值，把 one option 换成真实限制。

今日任务：说明一个功能的价值、当前限制和后续计划。

## Day 7：完成第一次完整 Demo

```text
Let me start with some context.
我先介绍一下背景。

The current process takes too many steps.
当前流程需要太多步骤。

I will show you the new flow.
我来演示新的流程。

First, I open the page and select an item.
首先，我打开页面并选择一项。

The result appears immediately.
结果会立即显示。

That covers the main flow.
主要流程就演示到这里。
```

替换练习：使用自己的产品内容替换 process、page、item 和 result。

今日任务：录制一段 60 秒 Demo，中途不要重录。

## Day 8：汇报工作进度

```text
Yesterday, I completed the implementation.
昨天我完成了开发。

Today, I am testing the new flow.
今天我正在测试新流程。

The main work is complete.
主要工作已经完成。

I still need to update the documentation.
我还需要更新文档。

My next step is to open the pull request.
我的下一步是创建 PR。

I expect to finish this today.
我预计今天完成。
```

替换练习：替换昨天、今天、下一步和完成时间。

今日任务：按照“昨天、今天、下一步”完成 30 秒站会汇报。

## Day 9：说明阻塞项和时间

```text
I am blocked by a permissions issue.
我被权限问题阻塞了。

I am waiting for access to the test environment.
我正在等待测试环境的访问权限。

There is one open question.
还有一个未解决的问题。

I need help from the backend team.
我需要后端团队的帮助。

If I get access today, I can finish by Friday.
如果今天获得权限，我可以在星期五前完成。

I will share an update this afternoon.
我会在今天下午同步进展。
```

替换练习：把 permissions issue、backend team 和 Friday 换成真实信息。

今日任务：清楚说明阻塞原因、需要谁帮助、预计时间和下一次更新。

## Day 10：Demo 出现意外

```text
It looks like the test environment is slow.
看起来测试环境有点慢。

Let me try that again.
我再试一次。

I will refresh the page.
我会刷新页面。

That is not the expected behavior.
这不是预期行为。

I will investigate this after the meeting.
我会在会后调查这个问题。

Let me continue with the next part.
我继续演示下一部分。
```

替换练习：把 slow 换成 unavailable，把 refresh the page 换成你的恢复操作。

今日任务：故意制造一次页面错误，然后不中断地解释并继续 Demo。

## Day 11：回答常见问题

```text
The short answer is yes.
简短回答是可以。

There are two parts to that question.
这个问题分为两部分。

This only affects new users.
这只影响新用户。

This does not change the existing workflow.
这不会改变现有流程。

That is outside the current scope.
这不在当前范围内。

We have not made a final decision yet.
我们还没有作出最终决定。
```

替换练习：把 new users 和 existing workflow 换成真实影响范围。

今日任务：让同事问你 3 个问题，每个回答至少包含结论和范围。

## Day 12：不知道答案时安全回应

```text
I do not have the exact number with me.
我现在没有准确数字。

I do not want to guess.
我不想猜测。

I need to check that with the team.
我需要和团队确认一下。

I will verify this after the meeting.
我会在会后确认。

I will follow up in the team chat.
我会在团队聊天中跟进。

Does that answer your question?
这样回答了你的问题吗？
```

替换练习：把 exact number 换成 release date、root cause 或 performance data。

今日任务：对 3 个不知道答案的问题作出诚实回应，并给出跟进方式。

## Day 13：邀请和澄清问题

```text
I will pause here and take questions.
我先停在这里回答问题。

What questions do you have?
大家有什么问题？

Could you clarify what you mean by performance?
可以说明一下你说的性能具体指什么吗？

Are you asking about the user experience or the implementation?
你问的是用户体验还是具体实现？

Could you give an example of that scenario?
可以举例说明那个场景吗？

Let me repeat the question to make sure I understood.
我复述一下问题，确认自己理解正确。
```

替换练习：把 performance 换成 security、compatibility 或 cost。

今日任务：完成一次 3 分钟问答练习，至少使用两句澄清表达。

## Day 14：完整会议与 Demo

```text
Hi everyone. Today, I will show the new user flow.
大家好，今天我会演示新的用户流程。

The goal is to reduce the number of manual steps.
目标是减少手动操作步骤。

First, I open the page and enter a keyword.
首先，我打开页面并输入关键词。

The matching results appear immediately.
匹配结果会立即显示。

This saves users time and makes the process clearer.
这可以节省用户时间，让流程更加清晰。

That covers the main flow. What questions do you have?
主要流程就演示到这里。大家有什么问题？
```

替换练习：把整段内容改成你的真实产品、用户和价值。

今日任务：完成 2 分钟脱稿 Demo 和 3 分钟 Q&A；遇到意外时使用 Day 10 或 Day 12 的表达继续。

## 结业标准

- 能在 3 秒内开始会议或 Demo。
- 能连续描述至少 6 个页面操作和结果。
- 能完成“背景、目标、操作、结果、价值、提问”的完整结构。
- 没听懂时能请求重复或澄清。
- 不知道答案时不猜测，能承诺明确的跟进方式。
- Demo 出错时能解释情况并继续，而不是沉默或退出。

完成后继续学习[软件职场英语语法全解](software-workplace-grammar-guide.zh.md)，重点复习一般现在时、现在进行时、一般过去时、将来表达、疑问句和情态动词。
