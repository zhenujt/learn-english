## Slide 3: Products Overview

Vega Platform covers six areas.

Vega Website    provides documentation and component references.

Vega MCP and Vega Assistant  provide Vega knowledge to AI tools and users.

Vega Telemetry   tracks component installation and usage.

We also provide Figma plugins, a testing library, and Vega Sandbox to support design, code generation, component testing, and online examples.

Next, I’ll show four key products.

## Slide 4: Vega Website

The first product is Vega Website.


It is a central website for Vega component documentation, guides, and live demos.


It provides one place to search and explore Vega component knowledge.

Users can view documentation and APIs, explore guides and examples, try live demos, and search all content. 


The demo image shows a component page where users can view configuration options, examples, guidelines, accessibility, and types.

## Slide 5: Vega MCP

The second product is Vega MCP.


It provides verified Vega component knowledge to AI development tools.

This helps AI use valid components, props, and up-to-date guidance.


Through MCP tools, AI can query component APIs, retrieve type definitions, get framework examples, and search versioned documentation.
