# Software Workplace Prepositions: Meetings, Speech, and Technical Communication

<!-- sentence-audio: fenced-only -->

> Learn relationships and reusable workplace phrases instead of memorizing one Chinese translation for each preposition.

[中文版本](software-workplace-prepositions.zh.md) · [Software Workplace Grammar](software-workplace-grammar-guide.md)

## 1. What a Preposition Does

A preposition shows the relationship between pieces of information. Common relationships include time, place, direction, recipient, reason, and method.

```text
The meeting starts at three.
会议三点开始。

The bug is in production.
这个 Bug 出现在生产环境。

I sent the report to Sarah.
我把报告发给了 Sarah。
```

Do not memorize isolated equations such as “for means 为了” or “in means 在.” Learn complete chunks instead: `for two hours`, `in production`, `on Monday`, and `with the backend team`.

## 2. First Clarification: and Is Not a Preposition

`And` is a conjunction. It connects words, actions, or clauses. Words such as `for`, `of`, `in`, and `on` are prepositions.

```text
I fixed the bug and updated the tests.
我修复了 Bug，并更新了测试。

The API is stable, and the deployment is complete.
API 很稳定，而且部署已经完成。
```

## 3. for: Aiming at a Target

Think of `for` as pointing toward a target. The target can be a duration, person, reason, or purpose.

### 3.1 for + duration

```text
We have been testing the fix for two hours.
我们已经测试这个修复两个小时了。

The service was unavailable for ten minutes.
服务中断了十分钟。

I worked on this task for three days.
我处理这个任务处理了三天。
```

`For two hours` gives a length of time. `Since 9 a.m.` gives the starting point.

```text
We have been waiting since 9 a.m.
我们从上午九点起一直在等待。
```

### 3.2 for + person or team

```text
I prepared a demo for the client.
我为客户准备了一个演示。

This dashboard is useful for the support team.
这个仪表盘对支持团队很有用。

Could you create an account for the new developer?
你可以为新开发人员创建一个账号吗？
```

### 3.3 for + reason

```text
Thank you for reviewing the pull request.
感谢你评审这个 PR。

I apologize for the delay.
我为这次延迟道歉。

The job failed for the same reason.
这个任务因为同样的原因失败了。
```

### 3.4 for + purpose

```text
We use this channel for release updates.
我们使用这个频道发布版本更新。

This endpoint is for internal use only.
这个端点仅供内部使用。

The flag is used for testing new features.
这个开关用于测试新功能。
```

## 4. of: Belonging, Parts, and Composition

Think of `of` as identifying ownership or a part of a whole.

```text
The cause of the issue is still unclear.
问题的原因仍不清楚。

One of the tests is failing.
其中一个测试失败了。

We need a copy of the production logs.
我们需要一份生产日志的副本。

Most of the work is complete.
大部分工作已经完成。
```

Useful chunks include `the status of the release`, `the owner of the task`, `the impact of the change`, `a list of issues`, and `the end of the sprint`. Do not translate every Chinese 的 with `of`; a short noun phrase such as `the release date` is often more natural.

## 5. at, on, and in for Time

| Preposition | Core image | Common times |
|---|---|---|
| `at` | a point | `at 3 p.m.`, `at noon`, `at night` |
| `on` | one calendar day | `on Monday`, `on September 6`, `on Friday morning` |
| `in` | a larger period | `in September`, `in 2026`, `in the morning` |

```text
The stand-up starts at 9:30.
站会九点半开始。

We will deploy on Friday.
我们将在星期五部署。

The migration will start in October.
迁移将在十月开始。

Can we discuss this in the afternoon?
我们可以下午讨论这件事吗？
```

Learn `at night`, `on time`, and `in time` as fixed chunks.

```text
The meeting started on time.
会议准时开始了。

We fixed the blocker in time for the release.
我们及时解决了阻塞项，赶上了发布。
```

`On time` means at the scheduled time. `In time` means early enough, before it is too late.

## 6. in: Inside a Range or Environment

```text
The error appears in the console.
错误出现在控制台中。

The fix is already in production.
这个修复已经在生产环境中。

We found three issues in the latest build.
我们在最新构建中发现了三个问题。

The task is in progress.
任务正在进行中。
```

Common environment chunks include `in development`, `in testing`, `in staging`, `in production`, `in the logs`, and `in the database`.

## 7. on: A Surface, Platform, Date, or Topic

```text
The issue occurs on mobile devices.
这个问题出现在移动设备上。

The documentation is on Confluence.
文档在 Confluence 上。

I am working on the authentication flow.
我正在处理身份验证流程。

Let us focus on the release risk.
我们重点讨论发布风险吧。
```

Learn `work on a task`, `focus on a problem`, `comment on a pull request`, `depend on a service`, and `on the agenda` as complete chunks.

## 8. at: A Point or Event

```text
I am at the office today.
我今天在办公室。

We discussed the roadmap at the planning meeting.
我们在规划会议上讨论了路线图。

The request failed at the validation step.
请求在验证步骤失败了。
```

`At the meeting` emphasizes the event. `In the meeting room` emphasizes being physically inside the room.

## 9. to and from: Direction and Source

`To` points to a destination, recipient, or result. `From` points to a starting point, source, or separation.

```text
Please send the logs to the backend team.
请把日志发给后端团队。

We moved the logic to the server.
我们把这个逻辑移到了服务器端。

The status changed from pending to approved.
状态从待处理变成了已批准。

This error comes from the payment service.
这个错误来自支付服务。
```

`To` can also be an infinitive marker. In `need to test`, it forms an infinitive and is not a preposition of direction.

## 10. with: Together, Using, or Having

```text
I will confirm the requirement with the product manager.
我会和产品经理确认需求。

We tested the endpoint with Postman.
我们使用 Postman 测试了这个端点。

There is a problem with the login flow.
登录流程存在问题。

The release includes a build with the security fix.
这个版本包含一个带有安全修复的构建。
```

Remember `work with someone`, `test with a tool`, and `a problem with something`.

## 11. by: Deadline, Agent, or Method

### 11.1 by + time: no later than

```text
Could you review the pull request by Friday?
你可以在星期五之前评审这个 PR 吗？

We need a decision by the end of the meeting.
我们需要在会议结束前做出决定。
```

`By Friday` gives a deadline. `On Friday` says when an event happens.

### 11.2 by + person: the agent

```text
The change was approved by the security team.
这个修改由安全团队批准。
```

### 11.3 by + method

```text
We reduced latency by caching the response.
我们通过缓存响应降低了延迟。

Please send the confirmation by email.
请通过电子邮件发送确认信息。
```

## 12. about: A Topic

```text
I have a question about the new requirement.
我对新需求有一个问题。

We need to talk about the deployment plan.
我们需要讨论部署计划。

The client is concerned about data security.
客户担心数据安全。
```

Common chunks include `ask about`, `talk about`, `a question about`, `concerned about`, and `information about`.

## 13. through, during, before, and after

`Through` emphasizes movement across a process or a means. `During` is followed by an event or period. `Before` and `after` show sequence.

```text
Let me walk you through the new workflow.
我带你逐步了解新的工作流程。

We discovered the issue during testing.
我们在测试期间发现了这个问题。

Please run the tests before deployment.
请在部署前运行测试。

We will monitor the service after the release.
发布后我们会监控服务。
```

Use `during` before a noun, as in `during the meeting`. Use `while` before a clause, as in `while we were testing`.

## 14. without: In the Absence of Something

```text
We cannot deploy without approval.
没有批准，我们不能部署。

The user can continue without refreshing the page.
用户无需刷新页面即可继续操作。

Please do not merge this change without running the tests.
没有运行测试，请不要合并这个修改。
```

`Without` is followed by a noun or an `-ing` form: `without approval`, `without testing`, or `without changing the API`.

## 15. High-Frequency Workplace Chunks

| Chunk | Meaning |
|---|---|
| `ask for help` | request help |
| `wait for approval` | wait until approval arrives |
| `prepare for the demo` | get ready for the demo |
| `responsible for testing` | have testing as a responsibility |
| `depend on the API` | require the API |
| `work on the issue` | spend effort on the issue |
| `focus on the root cause` | direct attention to the root cause |
| `interested in the proposal` | find the proposal interesting |
| `participate in the meeting` | take part in the meeting |
| `agree with someone` | share a person's opinion |
| `agree on a plan` | reach the same decision about a plan |
| `talk to the client` | speak with the client |
| `talk about the timeline` | discuss the timeline |
| `apologize for the delay` | say sorry for the delay |
| `a solution to the problem` | something that solves the problem |

```text
We are waiting for security approval.
我们正在等待安全审批。

Who is responsible for testing this change?
谁负责测试这个修改？

The client agreed with our recommendation.
客户同意了我们的建议。

We agreed on a smaller scope for this release.
我们就本次发布采用较小范围达成了一致。
```

## 16. Five Workplace Situations

### 16.1 Meetings

```text
Let us start with the first item on the agenda.
我们从议程上的第一项开始吧。

I have a question about the proposed timeline.
我对建议的时间安排有一个问题。

Can we agree on the next steps before the meeting ends?
我们能在会议结束前就下一步达成一致吗？
```

### 16.2 Daily Stand-ups

```text
I worked on the login issue for most of yesterday.
昨天大部分时间我都在处理登录问题。

I am waiting for access to the staging environment.
我正在等待预发布环境的访问权限。

I plan to finish the fix by this afternoon.
我计划最迟今天下午完成修复。
```

### 16.3 Bug Discussions

```text
The error occurs in production but not in staging.
这个错误出现在生产环境中，但不会出现在预发布环境中。

The problem started after the latest deployment.
这个问题在最近一次部署后开始出现。

We can reproduce it with an expired token.
我们可以使用过期令牌复现这个问题。
```

### 16.4 Pull Requests and Code Reviews

```text
I left two comments on the pull request.
我在这个 PR 上留下了两条评论。

This change depends on the new API contract.
这个修改依赖新的 API 契约。

Could you add a test for this edge case?
你可以为这个边界情况增加一个测试吗？
```

### 16.5 Demos

```text
I will walk you through the main workflow.
我会带你逐步了解主要工作流程。

When I click on this button, the dialog opens.
当我点击这个按钮时，弹框会打开。

This feature is designed for support agents.
这个功能是为支持人员设计的。
```

## 17. Easy-to-Confuse Pairs

### for and since

```text
We have worked on this feature for two weeks.
我们开发这个功能已经两周了。

We have worked on this feature since August.
我们从八月开始一直开发这个功能。
```

### by and until

```text
Please finish the review by five.
请最迟五点完成评审。

I will be in meetings until five.
我会一直开会到五点。
```

### in and into

```text
The data is in the database.
数据在数据库里。

The job writes the data into the database.
这个任务把数据写入数据库。
```

### on, in, and at for place

```text
The documentation is on Confluence.
文档在 Confluence 平台上。

The error is in the application.
错误在应用程序内部。

The team is at the office.
团队在办公室。
```

## 18. Common Errors

```text
Wrong: We discussed about the issue.
Correct: We discussed the issue.
```

```text
Wrong: Please explain me the problem.
Correct: Please explain the problem to me.
```

```text
Wrong: I am responsible of testing.
Correct: I am responsible for testing.
```

```text
Wrong: The meeting is in Monday.
Correct: The meeting is on Monday.
```

```text
Wrong: We will finish it until Friday.
Correct: We will finish it by Friday.
```

## 20. A Three-Part Learning Method

For each preposition, remember three things together:

1. A core relationship: `for` points toward a target.
2. A fixed chunk: `responsible for testing`.
3. Your own sentence: `I am responsible for testing the login flow.`

Listen to the complete lesson first and then repeat each example. On the second pass, produce the English from the Chinese. On the third pass, replace the task, person, tool, and time with details from your own work.
