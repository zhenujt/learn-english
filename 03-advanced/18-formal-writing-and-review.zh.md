# 18 正式写作、衔接与综合复盘

## 定义与核心公式

正式英语追求清晰、可验证、逻辑可追踪。段落公式：`主题句 + 解释/证据 + 例子/影响 + 小结或过渡`。用衔接词表达关系：递进 `furthermore`，转折 `however`，因果 `therefore`，举例 `for example`，结论 `therefore/in conclusion`。优先具体动词和可验证名词，少用空泛的 `very good`、`things`。

## 递进例句

1. `The update is useful because it saves time.`
2. `The update reduces manual work; however, it requires a short migration window.`
3. `The evidence suggests that automated checks improve reliability. Therefore, organizations should integrate them before deployment rather than treat them as an optional final step.`

## 常见错误

| 易错 | 正确 | 原因 |
|---|---|---|
| `In my opinion, I think ...` | `I think ...` / `In my opinion, ...` | 不重复表态。 |
| `Although ..., however, ...` | `Although ...` 或 `However, ...` | 不重复转折。 |
| `This is very very good.` | `This substantially improves reliability.` | 用精确词语。 |

## 综合自测与答案

写 80--120 词英文状态更新，必须包含：一个被动句、一个条件句、一个定语或名词性从句、一个衔接词。自查答案：主语动词完整；时态一致；从句内部为陈述语序；每个代词都有明确指代；没有中文标点。参考开头：`The issue was identified during testing. If the fix passes the final review, we will deploy it tomorrow. However, the team will continue monitoring the service that handles payments.`
