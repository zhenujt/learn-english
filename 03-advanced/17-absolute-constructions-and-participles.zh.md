# 17 独立主格与高级分词结构

## 定义与核心公式

分词短语压缩原因、时间、条件：`Having finished the test, we deployed.` 独立主格有自己的逻辑主语：`The test completed, we deployed the release.` 常见形式：`N + V-ing`、`N + V-ed`、`N + adj/prep phrase`。它更适合正式写作，口语优先用完整从句以避免歧义。

## 递进例句

1. `Feeling tired, I went home early.`
2. `With the configuration updated, the team restarted the service.`
3. `All relevant variables controlled, the researchers attributed the observed difference to the intervention.`

## 常见错误

| 易错 | 正确 | 原因 |
|---|---|---|
| `Driving to work, the rain started.` | `Driving to work, I saw the rain start.` | 分词逻辑主语不能是 `rain`。 |
| `Having deploy the app` | `Having deployed the app` | `having + 过去分词`。 |
| 无明确逻辑关系就强行压缩 | 用 `because/when/if` 完整从句 | 清晰优先。 |

## 自测与答案

1. 压缩：`Because the database was backed up, we started the migration.` 2. 改错：`Using the tool, the issue was found.` 3. 写一句 `With + 名词 + 过去分词`。答案：1. `With the database backed up, we started the migration.` 2. `Using the tool, we found the issue.`
