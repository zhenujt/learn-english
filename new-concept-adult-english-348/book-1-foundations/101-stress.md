# Lesson 101: Stress / 压力

> **Book 1** · Unit 9: 健康与情绪 · 难度：★☆☆☆☆

## 🎯 语法焦点

**将来时：be going to / will** — will 表临时决定、预测和承诺

## 📖 课文

Tomorrow, Alex Wang is going to delegate tasks. The release will happen on take short breaks. We are not going to overcommit this sprint. Alex Wang will handle everything alone as soon as possible.

## 📐 本课核心

**规则：** be going to + 动词原形：已计划好的将来行动。I am going to deploy tomorrow.

**示范：** `I am going to start the migration next week.` — 我下周要开始迁移。

**避免：** ❌ `She is going to goes.` → ✅ `She is going to go.`（going to 后用原形）

## ✏️ 练习

1. 仿照示范句，用"压力"的真实场景写一句英语。
2. 把 `She is going to goes.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
