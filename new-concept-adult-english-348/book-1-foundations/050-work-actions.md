# Lesson 050: Work Actions / 工作动作

> **Book 1** · Unit 5: 正在发生的事 · 难度：★☆☆☆☆

## 🎯 语法焦点

**现在进行时** — 现在进行时肯定句：I am writing code right now.

## 📖 课文

Mia Chen is busy. Mia Chen is designing a new screen a new feature this week. The designers are testing the prototype the screens. Nobody is joining a call right now. Everything is updating the board smoothly.

## 📐 本课核心

**规则：** 结构：am/is/are + 动词-ing。表示此刻正在发生或近期临时安排。

**示范：** `The system is processing your request.` — 系统正在处理你的请求。

**避免：** ❌ `She is work now.` → ✅ `She is working now.`（进行时动词要加 -ing）

## ✏️ 练习

1. 仿照示范句，用"工作动作"的真实场景写一句英语。
2. 把 `She is work now.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
