# Lesson 087: Making Plans / 约时间

> **Book 1** · Unit 8: 计划与邀请 · 难度：★☆☆☆☆

## 🎯 语法焦点

**过去进行时** — 过去进行时：was/were + doing

## 📖 课文

At 3 PM yesterday, Tom Park was run the regression tests. The server was update the test plan normally. Suddenly, the Thursday occurred. While Tom Park was automate the checks, a colleague miss the deadline.

## 📐 本课核心

**规则：** 结构：was/were + 动词-ing。表示过去某一时刻正在进行的动作。

**示范：** `They were discussing the plan at 3 PM.` — 下午三点他们在讨论方案。

**避免：** ❌ `She were sleeping.` → ✅ `She was sleeping.`（she 搭配 was）

## ✏️ 练习

1. 仿照示范句，用"约时间"的真实场景写一句英语。
2. 把 `She were sleeping.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
