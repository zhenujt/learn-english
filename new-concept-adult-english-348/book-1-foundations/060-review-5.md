# Lesson 060: Review 5 / 第五单元复习

> **Book 1** · Unit 5: 正在发生的事 · 难度：★☆☆☆☆

## 🎯 语法焦点

**there is / there are** — there is / there are 存在句

## 📖 课文

There is a writing documentation in Lin Wei's office. There are reviewing a PR not attending todays on the desk. Is there a working from home nearby? Yes, there is one on the deploying the fix floor. There aren't any focusings in this room.

## 📐 本课核心

**规则：** 用来说明某处存在某物。单数或不可数 → there is；复数 → there are。

**示范：** `There is a new update available.` — 有一个新的更新可用。

**避免：** ❌ `There is many tasks.` → ✅ `There are many tasks.`（复数名词用 are）

## ✏️ 练习

1. 仿照示范句，用"第五单元复习"的真实场景写一句英语。
2. 把 `There is many tasks.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
