# Lesson 053: Waiting / 等待

> **Book 1** · Unit 5: 正在发生的事 · 难度：★☆☆☆☆

## 🎯 语法焦点

**现在进行时** — 现在进行时否定与疑问：Are you testing?

## 📖 课文

Alex Wang is busy. Alex Wang is waiting for the build a new feature this week. The designers are downloading the update the screens. Nobody is loading the page right now. Everything is processing the request smoothly.

## 📐 本课核心

**规则：** 结构：am/is/are + 动词-ing。表示此刻正在发生或近期临时安排。

**示范：** `Are you deploying the fix?` — 你在部署修复吗？

**避免：** ❌ `She is work now.` → ✅ `She is working now.`（进行时动词要加 -ing）

## ✏️ 练习

1. 仿照示范句，用"等待"的真实场景写一句英语。
2. 把 `She is work now.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
