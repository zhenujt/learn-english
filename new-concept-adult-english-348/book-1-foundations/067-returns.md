# Lesson 067: Returns / 退换

> **Book 1** · Unit 6: 购买与服务 · 难度：★☆☆☆☆

## 🎯 语法焦点

**可数与不可数名词 / some & any** — some/any 在肯定/否定/疑问中 ⟲ 🔄

## 📖 课文

How much packaging does Ravi Gupta need? Not much. How many boxess are there? There are five. Ravi Gupta doesn't need any evidence today. Could I have some items, please?

## 📐 本课核心

**规则：** 可数名词有单复数：a task / tasks; an error / errors。

**示范：** `There aren't any available servers.` — 没有可用的服务器。

**避免：** ❌ `I need an information.` → ✅ `I need some information.`（information 不可数）

## ✏️ 练习

1. 仿照示范句，用"退换"的真实场景写一句英语。
2. 把 `I need an information.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
