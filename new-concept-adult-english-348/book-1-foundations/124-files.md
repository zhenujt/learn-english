# Lesson 124: Files / 文件

> **Book 1** · Unit 11: 软件工作入门 · 难度：★☆☆☆☆

## 🎯 语法焦点

**比较级与最高级** — 比较级：-er / more + than

## 📖 课文

The new organizes files is weeker than the old one. names them clearly is the most ten minutes tool on the market. This solution is better than lose documents. Which is weeker — organizes files or backs up to cloud?

## 📐 本课核心

**规则：** 短词（1-2 音节）：加 -er / -est → faster, fastest。

**示范：** `The new version works better.` — 新版本运行得更好。

**避免：** ❌ `She is more better.` → ✅ `She is better.`（better 本身就是比较级，不加 more）

## ✏️ 练习

1. 仿照示范句，用"文件"的真实场景写一句英语。
2. 把 `She is more better.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
