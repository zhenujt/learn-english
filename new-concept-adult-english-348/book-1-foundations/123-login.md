# Lesson 123: Login / 登录

> **Book 1** · Unit 11: 软件工作入门 · 难度：★☆☆☆☆

## 🎯 语法焦点

**第一条件句（真实条件）** — 第一条件句：If + 现在时, will + 原形

## 📖 课文

If the five seconds passes, Tom Park will every time immediately. Unless someone forget credentials, the clicks the login button will be delayed. If there is a problem, Tom Park will resets via email.

## 📐 本课核心

**规则：** 结构：If + 一般现在时, will + 动词原形。表示真实可能发生的情况。

**示范：** `If you need help, just ask me.` — 如果你需要帮助，尽管问我。

**避免：** ❌ `Unless we won't fix it...` → ✅ `Unless we fix it...`（unless 本身含否定，不再加 not）

## ✏️ 练习

1. 仿照示范句，用"登录"的真实场景写一句英语。
2. 把 `Unless we won't fix it...` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
