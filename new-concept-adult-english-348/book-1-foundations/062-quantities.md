# Lesson 062: Quantities / 数量

> **Book 1** · Unit 6: 购买与服务 · 难度：★☆☆☆☆

## 🎯 语法焦点

**可数与不可数名词 / some & any** — 可数名词 + a/an/some/any

## 📖 课文

Mia Chen needs some water. There isn't any sugar left. "Do you have any cups?" "Yes, here are two cupss." Mia Chen also wants a piece of advice. There is a lot of software to review.

## 📐 本课核心

**规则：** 可数名词有单复数：a task / tasks; an error / errors。

**示范：** `There aren't any available servers.` — 没有可用的服务器。

**避免：** ❌ `She has many softwares.` → ✅ `She has a lot of software.`（software 不可数）

## ✏️ 练习

1. 仿照示范句，用"数量"的真实场景写一句英语。
2. 把 `She has many softwares.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
