# Lesson 061: Food / 食物

> **Book 1** · Unit 6: 购买与服务 · 难度：★☆☆☆☆

## 🎯 语法焦点

**可数与不可数名词 / some & any** — 可数名词 + a/an/some/any

## 📖 课文

How much milk does Lin Wei need? Not much. How many sandwichess are there? There are five. Lin Wei doesn't need any cake today. Could I have some coffee, please?

## 📐 本课核心

**规则：** 可数名词有单复数：a task / tasks; an error / errors。

**示范：** `I need some information about the API.` — 我需要一些关于这个 API 的信息。

**避免：** ❌ `I need an information.` → ✅ `I need some information.`（information 不可数）

## ✏️ 练习

1. 仿照示范句，用"食物"的真实场景写一句英语。
2. 把 `I need an information.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
