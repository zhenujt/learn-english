# Lesson 115: Chat Messages / 聊天消息

> **Book 1** · Unit 10: 电话与消息 · 难度：★☆☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — 情态动词综合 ⟲（can/should/must 对比） 🔄

## 📖 课文

"Can I post in the channel?" "Yes, you can." "Ravi Gupta must tag the right person today." "You should also before lunch." "Ravi Gupta can't flood the chat right now — the system is down."

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `You shouldn't skip code review.` — 你不应该跳过代码审查。

**避免：** ❌ `She can speaks English.` → ✅ `She can speak English.`（情态动词后用原形）

## ✏️ 练习

1. 仿照示范句，用"聊天消息"的真实场景写一句英语。
2. 把 `She can speaks English.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
