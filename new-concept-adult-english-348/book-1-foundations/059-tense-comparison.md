# Lesson 059: Tense Comparison / 对比时态

> **Book 1** · Unit 5: 正在发生的事 · 难度：★☆☆☆☆

## 🎯 语法焦点

**there is / there are** — there is / there are 存在句

## 📖 课文

In James Hu's team, there are always checking twice developers. There is one usually finishing by five and there is also a coding right now. There aren't any reviewings this week. There is a lot of work to do.

## 📐 本课核心

**规则：** 用来说明某处存在某物。单数或不可数 → there is；复数 → there are。

**示范：** `There aren't any empty desks.` — 没有空桌子了。

**避免：** ❌ `It has a bug in the code.` → ✅ `There is a bug in the code.`（表示存在用 there is，不用 it has）

## ✏️ 练习

1. 仿照示范句，用"对比时态"的真实场景写一句英语。
2. 把 `It has a bug in the code.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
