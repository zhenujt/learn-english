# Lesson 137: Asking for Help / 请求帮助

> **Book 1** · Unit 12: 综合复习 · 难度：★☆☆☆☆

## 🎯 语法焦点

**现在进行时** — 进行时 + 条件句综合 ⟲ 🔄

## 📖 课文

Alex Wang is busy. Alex Wang is pair-program a new feature this week. The designers are ask the tech lead the screens. Nobody is fix it alone right now. Everything is panic smoothly.

## 📐 本课核心

**规则：** 结构：am/is/are + 动词-ing。表示此刻正在发生或近期临时安排。

**示范：** `She is not attending today's standup.` — 她今天不参加站会。

**避免：** ❌ `She is work now.` → ✅ `She is working now.`（进行时动词要加 -ing）

## ✏️ 练习

1. 仿照示范句，用"请求帮助"的真实场景写一句英语。
2. 把 `She is work now.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
