# Lesson 113: Network Issues / 网络问题

> **Book 1** · Unit 10: 电话与消息 · 难度：★☆☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — must / mustn't / have to 表义务

## 📖 课文

"Can I reconnect in a moment?" "Yes, you can." "Alex Wang must try a different network today." "You should also shortly." "Alex Wang can't ignore the lag right now — the system is down."

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `We must finish this before Friday.` — 我们必须在周五前完成。

**避免：** ❌ `You should to check it.` → ✅ `You should check it.`（should 后不加 to）

## ✏️ 练习

1. 仿照示范句，用"网络问题"的真实场景写一句英语。
2. 把 `You should to check it.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
