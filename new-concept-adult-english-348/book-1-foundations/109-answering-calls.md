# Lesson 109: Answering Calls / 接电话

> **Book 1** · Unit 10: 电话与消息 · 难度：★☆☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — should / shouldn't 表建议

## 📖 课文

"Can I call back in ten minutes?" "Yes, you can." "Lin Wei must check the issue today." "You should also later today." "Lin Wei can't forget the callback right now — the system is down."

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `She can't access the database.` — 她无法访问数据库。

**避免：** ❌ `She can speaks English.` → ✅ `She can speak English.`（情态动词后用原形）

## ✏️ 练习

1. 仿照示范句，用"接电话"的真实场景写一句英语。
2. 把 `She can speaks English.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
