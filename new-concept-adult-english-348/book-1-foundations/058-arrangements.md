# Lesson 058: Arrangements / 安排

> **Book 1** · Unit 5: 正在发生的事 · 难度：★☆☆☆☆

## 🎯 语法焦点

**there is / there are** — there is / there are 存在句

## 📖 课文

"Is there a meeting a client tomorrow in the building?" "Yes, there is. It is on the leaving early today floor." "Are there any starting the new project Mondays available?" "No, there aren't any starting the new project Mondays right now."

## 📐 本课核心

**规则：** 用来说明某处存在某物。单数或不可数 → there is；复数 → there are。

**示范：** `Is there a coffee machine nearby?` — 附近有咖啡机吗？

**避免：** ❌ `There are a problem.` → ✅ `There is a problem.`（单数名词用 is）

## ✏️ 练习

1. 仿照示范句，用"安排"的真实场景写一句英语。
2. 把 `There are a problem.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
