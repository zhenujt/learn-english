# Lesson 140: Work Update / 工作更新

> **Book 1** · Unit 12: 综合复习 · 难度：★☆☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — 情态 + 比较综合 ⟲ 🔄

## 📖 课文

Emma Liu can finishing the feature quickly. Emma Liu should testing edge cases before the meeting. The team must not blocking anyone by Friday. You shouldn't preparing the release notes without testing. Can you waiting for review?

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `You shouldn't skip code review.` — 你不应该跳过代码审查。

**避免：** ❌ `You should to check it.` → ✅ `You should check it.`（should 后不加 to）

## ✏️ 练习

1. 仿照示范句，用"工作更新"的真实场景写一句英语。
2. 把 `You should to check it.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
