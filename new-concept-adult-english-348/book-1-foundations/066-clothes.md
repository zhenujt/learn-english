# Lesson 066: Clothes / 衣物

> **Book 1** · Unit 6: 购买与服务 · 难度：★☆☆☆☆

## 🎯 语法焦点

**可数与不可数名词 / some & any** — 不可数名词 + how much / how many

## 📖 课文

Yuki Tanaka needs some shirts. There isn't any cotton left. "Do you have any pairs?" "Yes, here are two pairss." Yuki Tanaka also wants a piece of experience. There is a lot of homework to review.

## 📐 本课核心

**规则：** 可数名词有单复数：a task / tasks; an error / errors。

**示范：** `I need some information about the API.` — 我需要一些关于这个 API 的信息。

**避免：** ❌ `I don't have some time.` → ✅ `I don't have any time.`（否定句用 any）

## ✏️ 练习

1. 仿照示范句，用"衣物"的真实场景写一句英语。
2. 把 `I don't have some time.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
