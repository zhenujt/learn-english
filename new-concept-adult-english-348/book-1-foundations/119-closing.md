# Lesson 119: Closing / 结束语

> **Book 1** · Unit 10: 电话与消息 · 难度：★☆☆☆☆

## 🎯 语法焦点

**将来时：be going to / will** — 将来时 + 情态动词综合 ⟲ 🔄

## 📖 课文

Tomorrow, James Hu is going to wrap up the call. The release will happen on in two minutes. We are not going to end abruptly this sprint. James Hu will summarize the action items as soon as possible.

## 📐 本课核心

**规则：** be going to + 动词原形：已计划好的将来行动。I am going to deploy tomorrow.

**示范：** `Will the release be on time?` — 发布会准时吗？

**避免：** ❌ `She is going to goes.` → ✅ `She is going to go.`（going to 后用原形）

## ✏️ 练习

1. 仿照示范句，用"结束语"的真实场景写一句英语。
2. 把 `She is going to goes.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
