# Lesson 110: Leaving Messages / 留言

> **Book 1** · Unit 10: 电话与消息 · 难度：★☆☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — should / shouldn't 表建议

## 📖 课文

Mia Chen can send a follow-up email quickly. Mia Chen should this afternoon before the meeting. The team must include the details by Friday. You shouldn't lose the message without testing. Can you record the key points?

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `You shouldn't skip code review.` — 你不应该跳过代码审查。

**避免：** ❌ `You should to check it.` → ✅ `You should check it.`（should 后不加 to）

## ✏️ 练习

1. 仿照示范句，用"留言"的真实场景写一句英语。
2. 把 `You should to check it.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
