# Lesson 331: Recommendation Writing / 建议方案

> **Book 4** · Unit 8: 数据驱动建议 · 难度：★★★★☆

## 🎯 语法焦点

**论证结构：主张、证据、结论** — 论证综合 ⟲ 🔄

## 📖 课文

The increase cache TTL presents a challenge. Research indicates that reduce database load. Although stale data risk, the benefits of monitoring shows 70% cache hits outweigh the costs. Consequently, Tom Park recommends implement next sprint.

## 📐 本课核心

**规则：** 论证四步：主张 (claim) → 理由 (reason) → 证据 (evidence) → 结论 (conclusion)。

**示范：** `We should migrate to the cloud. The current servers are reaching capacity, and cloud services offer better scalability.` — 我们应该迁移到云端。当前服务器接近容量上限，云服务提供更好的扩展性。

**避免：** ❌ `We should do this because I think so.` → ✅ `We should do this because data shows a 30% improvement.`（论证需要证据，不能只用个人观点）

## ✏️ 练习

1. 仿照示范句，用"建议方案"的真实场景写一句英语。
2. 把 `We should do this because I think so.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
