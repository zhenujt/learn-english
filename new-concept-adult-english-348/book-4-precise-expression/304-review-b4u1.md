# Lesson 304: Review B4U1 / 复习

> **Book 4** · Unit 1: 假设与反思 · 难度：★★★★☆

## 🎯 语法焦点

**第三条件句（与过去事实相反的假设）** — 第三条件句：If + had pp, would have pp

## 📖 课文

If Sara Li had planned capacity, the team would have handled the spike. The communicated earlier could have been avoided if someone had avoided the confusion. Had we set up monitoring, the detected the issue sooner would have been different.

## 📐 本课核心

**规则：** 结构：If + had + 过去分词, would have + 过去分词。表示过去没有发生的假设。

**示范：** `The outage could have been avoided if the config had been reviewed.` — 如果配置被审查过，这次宕机本可避免。

**避免：** ❌ `If we would have tested...` → ✅ `If we had tested...`（if 从句不用 would）

## ✏️ 练习

1. 仿照示范句，用"复习"的真实场景写一句英语。
2. 把 `If we would have tested...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
