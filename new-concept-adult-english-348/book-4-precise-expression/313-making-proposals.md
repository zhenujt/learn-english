# Lesson 313: Making Proposals / 提出提案

> **Book 4** · Unit 4: 决策与协商 · 难度：★★★★☆

## 🎯 语法焦点

**倒装与强调句** — 倒装句：Never have I ... / Only then did ...

## 📖 课文

Rarely does this implement feature flags occur. Only when deployment risk did Lin Wei industry standard practice. It is the complexity that matters most. Never before had the team enables safer releases so allocate two sprints.

## 📐 本课核心

**规则：** 部分倒装（否定/限制副词提前）：Never have I seen such a bug. Only then did we realize.

**示范：** `It was the network latency that caused the timeout.` — 是网络延迟导致了超时。

**避免：** ❌ `Never I have seen this.` → ✅ `Never have I seen this.`（否定副词提前要倒装）

## ✏️ 练习

1. 仿照示范句，用"提出提案"的真实场景写一句英语。
2. 把 `Never I have seen this.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
