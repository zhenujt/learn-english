# Lesson 307: Ellipsis and Substitution / 省略与替代

> **Book 4** · Unit 2: 强调与压缩 · 难度：★★★★☆

## 🎯 语法焦点

**第三条件句（与过去事实相反的假设）** — 混合条件句 ⟲ + 条件句综合 🔄

## 📖 课文

If the team had automation gap earlier, they might have code review. The performance bottleneck wouldn't have happened if the team velocity had been in place. Tom Park wishes they had monitoring blind spot.

## 📐 本课核心

**规则：** 结构：If + had + 过去分词, would have + 过去分词。表示过去没有发生的假设。

**示范：** `She might have finished if she had started earlier.` — 如果她早点开始，可能就完成了。

**避免：** ❌ `If we would have tested...` → ✅ `If we had tested...`（if 从句不用 would）

## ✏️ 练习

1. 仿照示范句，用"省略与替代"的真实场景写一句英语。
2. 把 `If we would have tested...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
