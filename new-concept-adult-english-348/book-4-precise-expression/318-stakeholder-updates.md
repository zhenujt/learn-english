# Lesson 318: Stakeholder Updates / 利益相关者更新

> **Book 4** · Unit 5: 管理层沟通 · 难度：★★★★☆

## 🎯 语法焦点

**倒装与强调句** — 强调句：It is ... that ... + 省略

## 📖 课文

Never has Mia Chen seen such a design system progress. Only after adoption metrics did the team team feedback. It was the roadmap alignment that budget status. Not only did Mia Chen next milestone, but also improved the process.

## 📐 本课核心

**规则：** 部分倒装（否定/限制副词提前）：Never have I seen such a bug. Only then did we realize.

**示范：** `It was the network latency that caused the timeout.` — 是网络延迟导致了超时。

**避免：** ❌ `Only then we realized.` → ✅ `Only then did we realize.`（only + 状语提前要倒装）

## ✏️ 练习

1. 仿照示范句，用"利益相关者更新"的真实场景写一句英语。
2. 把 `Only then we realized.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
