# Lesson 315: Handling Objections / 处理异议

> **Book 4** · Unit 4: 决策与协商 · 难度：★★★★☆

## 🎯 语法焦点

**倒装与强调句** — 倒装句：Never have I ... / Only then did ...

## 📖 课文

Rarely does this acknowledged the concern occur. Only when cost did Tom Park high. It is the justified that matters most. Never before had the team provided data so stakeholder agreed.

## 📐 本课核心

**规则：** 部分倒装（否定/限制副词提前）：Never have I seen such a bug. Only then did we realize.

**示范：** `Rarely does this error occur in production.` — 这个错误在生产环境中很少出现。

**避免：** ❌ `Only then we realized.` → ✅ `Only then did we realize.`（only + 状语提前要倒装）

1. 仿照示范句，用"处理异议"的真实场景写一句英语。
2. 把 `Only then we realized.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
