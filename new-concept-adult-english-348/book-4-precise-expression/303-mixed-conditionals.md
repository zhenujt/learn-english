# Lesson 303: Mixed Conditionals / 混合条件句

> **Book 4** · Unit 1: 假设与反思 · 难度：★★★★☆

## 🎯 语法焦点

**第二条件句（与现在事实相反的假设）** — 第二条件句：If + 过去式, would + 原形

## 📖 课文

If the team were invested in testing, Tom Park would be finished now. We could have fewer incidents if we had more started earlier. If conditions were different, Tom Park would be in a stronger position.

## 📐 本课核心

**规则：** 结构：If + 过去式, would + 动词原形。表示现在不太可能或与事实相反。

**示范：** `We could release earlier if we had more developers.` — 如果有更多开发者，我们可以更早发布。

**避免：** ❌ `If she has more time, she would help.` → ✅ `If she had more time, she would help.`（第二条件句 if 从句用过去式）

## ✏️ 练习

1. 仿照示范句，用"混合条件句"的真实场景写一句英语。
2. 把 `If she has more time, she would help.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
