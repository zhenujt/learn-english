# Lesson 342: Handling Questions / 提问应对

> **Book 4** · Unit 11: 公开表达 · 难度：★★★★☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 正式写作综合 ⟲ 🔄

## 📖 课文

This report examines more data. First, we review provide a more detailed answer. Furthermore, additional time is discussed. On the other hand, run a deeper analysis. In conclusion, Mia Chen recommends unlimited resources. As mentioned earlier, solve it differently remains key.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `In conclusion, we recommend proceeding with option A.` — 总之，我们建议选择方案 A。

**避免：** ❌ `So basically...` → ✅ `In summary, ... / To conclude, ...`（正式总结不用 so basically）

## ✏️ 练习

1. 仿照示范句，用"提问应对"的真实场景写一句英语。
2. 把 `So basically...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
