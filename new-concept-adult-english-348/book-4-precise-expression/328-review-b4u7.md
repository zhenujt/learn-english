# Lesson 328: Review B4U7 / 复习

> **Book 4** · Unit 7: 架构与安全 · 难度：★★★★☆

## 🎯 语法焦点

**论证结构：主张、证据、结论** — 论证：让步与反驳（Admittedly ...; however ...）

## 📖 课文

Alex Wang proposes that we adopt zero-trust networking. The primary reason is security posture. Evidence shows that NIST framework alignment. Admittedly, implementation cost; however, breach prevention value. Therefore, we recommend phase over three quarters.

## 📐 本课核心

**规则：** 论证四步：主张 (claim) → 理由 (reason) → 证据 (evidence) → 结论 (conclusion)。

**示范：** `For this reason, we recommend a phased approach.` — 因此，我们推荐分阶段方案。

**避免：** ❌ `We should do this because I think so.` → ✅ `We should do this because data shows a 30% improvement.`（论证需要证据，不能只用个人观点）

## ✏️ 练习

1. 仿照示范句，用"复习"的真实场景写一句英语。
2. 把 `We should do this because I think so.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
