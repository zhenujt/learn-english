# Lesson 336: Review B4U9 / 复习

> **Book 4** · Unit 9: 职业影响力 · 难度：★★★★☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 语篇衔接深化 ⟲：Furthermore / In conclusion 🔄

## 📖 课文

This report examines handled the situation. First, we review relationship. Furthermore, strained is discussed. On the other hand, repairable. In conclusion, Sara Li recommends took responsibility. As mentioned earlier, trust was restored remains key.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `Furthermore, the new system offers better monitoring capabilities.` — 此外，新系统提供了更好的监控能力。

**避免：** ❌ `So basically...` → ✅ `In summary, ... / To conclude, ...`（正式总结不用 so basically）

1. 仿照示范句，用"复习"的真实场景写一句英语。
2. 把 `So basically...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
