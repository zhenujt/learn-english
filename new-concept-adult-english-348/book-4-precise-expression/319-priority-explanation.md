# Lesson 319: Priority Explanation / 优先级说明

> **Book 4** · Unit 5: 管理层沟通 · 难度：★★★★☆

## 🎯 语法焦点

**倒装与强调句** — 强调与压缩综合 ⟲ 🔄

## 📖 课文

Rarely does this prioritize reliability over features occur. Only when user trust did Tom Park three outages last quarter. It is the feature delay that matters most. Never before had the team retention data supports this so defer feature work one sprint.

## 📐 本课核心

**规则：** 部分倒装（否定/限制副词提前）：Never have I seen such a bug. Only then did we realize.

**示范：** `Not only did she find the bug, but she also fixed it.` — 她不仅发现了缺陷，还修复了它。

**避免：** ❌ `Never I have seen this.` → ✅ `Never have I seen this.`（否定副词提前要倒装）

## ✏️ 练习

1. 仿照示范句，用"优先级说明"的真实场景写一句英语。
2. 把 `Never I have seen this.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
