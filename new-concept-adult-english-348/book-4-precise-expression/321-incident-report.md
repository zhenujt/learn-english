# Lesson 321: Incident Report / 事件报告

> **Book 4** · Unit 6: 正式报告 · 难度：★★★★☆

## 🎯 语法焦点

**倒装与强调句** — 强调与压缩综合 ⟲ 🔄

## 📖 课文

Rarely does this detected the anomaly occur. Only when already escalated did Lin Wei had failed silently. It is the deployed the patch that matters most. Never before had the team had restored service so documented the timeline.

## 📐 本课核心

**规则：** 部分倒装（否定/限制副词提前）：Never have I seen such a bug. Only then did we realize.

**示范：** `Never have I seen such a complex system.` — 我从未见过如此复杂的系统。

**避免：** ❌ `Only then we realized.` → ✅ `Only then did we realize.`（only + 状语提前要倒装）

## ✏️ 练习

1. 仿照示范句，用"事件报告"的真实场景写一句英语。
2. 把 `Only then we realized.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
