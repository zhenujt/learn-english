# Lesson 267: User Stories / 用户故事

> **Book 3** · Unit 6: 需求与设计 · 难度：★★★☆☆

## 🎯 语法焦点

**动名词与不定式** — 动名词 vs 不定式：enjoy doing / decide to do

## 📖 课文

Mia Chen considered onboarding but decided to create a user profile instead. Simplifying takes time. She suggested avoid confusing navigation first. They agreed to plan to add tooltips by Friday.

## 📐 本课核心

**规则：** 动名词 (V-ing) 作名词用：Testing is important. I enjoy coding.

**示范：** `She decided to rewrite the module.` — 她决定重写这个模块。

**避免：** ❌ `I want learning Python.` → ✅ `I want to learn Python.`（want 后接不定式）

## ✏️ 练习

1. 仿照示范句，用"用户故事"的真实场景写一句英语。
2. 把 `I want learning Python.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
