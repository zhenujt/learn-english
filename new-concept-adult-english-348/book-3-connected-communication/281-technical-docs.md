# Lesson 281: Technical Docs / 技术文档

> **Book 3** · Unit 9: 文档与数据 · 难度：★★★☆☆

## 🎯 语法焦点

**高级被动语态** — 时态与语态综合 ⟲ 🔄

## 📖 课文

The API documentation can be endpoint descriptions automatically. It had been authentication flow before the deadline. error codess are being rate limits this week. The decision must be versioning strategy by management.

## 📐 本课核心

**规则：** 情态动词 + 被动：can/should/must + be + 过去分词。

**示范：** `The issue should be resolved by tomorrow.` — 这个问题应该在明天前解决。

**避免：** ❌ `The code has reviewed.` → ✅ `The code has been reviewed.`（完成时被动需要 been）
