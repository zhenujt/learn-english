# Lesson 298: Design Review / 设计评审

> **Book 3** · Unit 12: 综合实践 · 难度：★★★☆☆

## 🎯 语法焦点

**论证结构：主张、证据、结论** — 第三册毕业综合 ⟲（从句 + 非谓语 + 段落 + 缓和） 🔄

## 📖 课文

Tom Park proposes that we adopt event sourcing. The primary reason is auditability. Evidence shows that industry best practice. Admittedly, complexity increase; however, team training cost. Therefore, we recommend recommend gradual adoption.

## 📐 本课核心

**规则：** 论证四步：主张 (claim) → 理由 (reason) → 证据 (evidence) → 结论 (conclusion)。

**示范：** `For this reason, we recommend a phased approach.` — 因此，我们推荐分阶段方案。

**避免：** ❌ `We should do this because I think so.` → ✅ `We should do this because data shows a 30% improvement.`（论证需要证据，不能只用个人观点）

## ✏️ 练习

1. 仿照示范句，用"设计评审"的真实场景写一句英语。
2. 把 `We should do this because I think so.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
