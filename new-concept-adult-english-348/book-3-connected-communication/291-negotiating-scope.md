# Lesson 291: Negotiating Scope / 协商范围

> **Book 3** · Unit 11: 复杂工作关系 · 难度：★★★☆☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 平行结构与信息密度 ⟲ 🔄

## 📖 课文

The following section addresses resources. In addition to deliver all features, we consider team. However, double the size should not be overlooked. To summarize, the best approach is cut scope.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `Furthermore, the new system offers better monitoring capabilities.` — 此外，新系统提供了更好的监控能力。

**避免：** ❌ `So basically...` → ✅ `In summary, ... / To conclude, ...`（正式总结不用 so basically）

2. 把 `So basically...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
