# Lesson 286: Presentation Opening / 演示开场

> **Book 3** · Unit 10: 展示与影响 · 难度：★★★☆☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 衔接手段：过渡词 / 指代 / 重复关键词

## 📖 课文

This report examines project overview. First, we review problem statement. Furthermore, proposed solution is discussed. On the other hand, expected impact. In conclusion, Lin Wei recommends implementation plan. As mentioned earlier, timeline remains key.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `Furthermore, the new system offers better monitoring capabilities.` — 此外，新系统提供了更好的监控能力。

**避免：** ❌ `And also we need...` → ✅ `Furthermore, we need... / In addition, ...`（正式写作避免 and also 开头）

## ✏️ 练习

1. 仿照示范句，用"演示开场"的真实场景写一句英语。
2. 把 `And also we need...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
