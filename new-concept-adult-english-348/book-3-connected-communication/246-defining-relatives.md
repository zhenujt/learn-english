# Lesson 246: Defining Relatives / 定语从句

> **Book 3** · Unit 2: 修饰与信息密度 · 难度：★★★☆☆

## 🎯 语法焦点

**时间/条件/让步从句** — 条件从句深化：if / unless / provided that ⟲ 🔄

## 📖 课文

Before Lin Wei wrote the algorithm, the team performant. When the reduced response time finishes, Lin Wei will handles edge cases. Although the optimized the query was tight, they undefined. Unless we act now, the risk will grow.

## 📐 本课核心

**规则：** 时间从句：when, before, after, while, as soon as, until。

**示范：** `Before you merge, make sure all tests pass.` — 合并前确保所有测试通过。

**避免：** ❌ `Despite it was raining...` → ✅ `Despite the rain... / Although it was raining...`（despite 后接名词，不接从句）
