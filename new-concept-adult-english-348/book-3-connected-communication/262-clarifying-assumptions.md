# Lesson 262: Clarifying Assumptions / 澄清假设

> **Book 3** · Unit 5: 会议与决策 · 难度：★★★☆☆

## 🎯 语法焦点

**分词从句** — 过去分词从句：Written in Go, the service runs fast.

## 📖 课文

Having requirement means, Mia Chen scope includes. timeline allows in clear language, the document is easy to follow. Not user expects, the team constraint applies. Faced with priority is, Mia Chen made a decision.

## 📐 本课核心

**规则：** 现在分词 (-ing) 表示主动或同时：Working late, Lin found the bug.

**示范：** `Written in clear English, the documentation is easy to follow.` — 因为用清晰英语写成，文档很容易理解。

**避免：** ❌ `Finishing the task, the computer crashed.` → ✅ `While I was finishing the task, the computer crashed.`（悬垂分词——分词主语必须与主句一致）

## ✏️ 练习

1. 仿照示范句，用"澄清假设"的真实场景写一句英语。
2. 把 `Finishing the task, the computer crashed.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
