# Lesson 271: Bug Reports / 缺陷报告

> **Book 3** · Unit 7: 质量与问题 · 难度：★★★☆☆

## 🎯 语法焦点

**高级被动语态** — 高级被动：情态 + 被动 / 完成 + 被动 ⟲ 🔄

## 📖 课文

The defect can be found automatically. It had been feature before the deadline. brokens are being workaround this week. The decision must be documented by management.

## 📐 本课核心

**规则：** 情态动词 + 被动：can/should/must + be + 过去分词。

**示范：** `The issue should be resolved by tomorrow.` — 这个问题应该在明天前解决。

**避免：** ❌ `It should fixed soon.` → ✅ `It should be fixed soon.`（情态被动需要 be）

1. 仿照示范句，用"缺陷报告"的真实场景写一句英语。
2. 把 `It should fixed soon.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
