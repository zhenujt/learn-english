# Lesson 294: Cross-team Work / 跨团队合作

> **Book 3** · Unit 11: 复杂工作关系 · 难度：★★★☆☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 段落写作综合 ⟲ 🔄

## 📖 课文

This report examines finalizes the API contract. First, we review begin integration. Furthermore, dependency resolves is discussed. On the other hand, unblock development. In conclusion, Sara Li recommends timeline was uncertain. As mentioned earlier, coordinated effectively remains key.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `On the other hand, the alternative requires less upfront investment.` — 另一方面，替代方案需要的前期投入更少。

**避免：** ❌ `So basically...` → ✅ `In summary, ... / To conclude, ...`（正式总结不用 so basically）

## ✏️ 练习

1. 仿照示范句，用"跨团队合作"的真实场景写一句英语。
2. 把 `So basically...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
