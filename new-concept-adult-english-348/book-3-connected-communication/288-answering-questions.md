# Lesson 288: Answering Questions / 回答问题

> **Book 3** · Unit 10: 展示与影响 · 难度：★★★☆☆

## 🎯 语法焦点

**语篇衔接与正式写作** — 衔接手段：过渡词 / 指代 / 重复关键词

## 📖 课文

This report examines more budget. First, we review hire specialists. Furthermore, unlimited time is discussed. On the other hand, refactor everything. In conclusion, Tom Park recommends perfect conditions. As mentioned earlier, deliver faster remains key.

## 📐 本课核心

**规则：** 主题句：每段第一句概括该段要点。

**示范：** `This approach has two main benefits. First, it reduces cost. Second, it improves reliability.` — 这个方案有两个主要好处。第一，降低成本。第二，提高可靠性。

**避免：** ❌ `So basically...` → ✅ `In summary, ... / To conclude, ...`（正式总结不用 so basically）

## ✏️ 练习

1. 仿照示范句，用"回答问题"的真实场景写一句英语。
2. 把 `So basically...` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
