# Lesson 280: Review B3U8 / 复习

> **Book 3** · Unit 8: 代码协作 · 难度：★★★☆☆

## 🎯 语法焦点

**高级被动语态** — 时态与语态综合 ⟲ 🔄

## 📖 课文

The simplified the logic should be clean by Friday. The system has been improved error handling successfully. A new reduced boilerplate is being enhanced documentation now. All changes must be undefined first.

## 📐 本课核心

**规则：** 情态动词 + 被动：can/should/must + be + 过去分词。

**示范：** `The report had been submitted before the deadline.` — 报告在截止日期前已经提交了。

**避免：** ❌ `It should fixed soon.` → ✅ `It should be fixed soon.`（情态被动需要 be）

## ✏️ 练习

1. 仿照示范句，用"复习"的真实场景写一句英语。
2. 把 `It should fixed soon.` 改正，并说明原因。
3. 用本课语法焦点说 5 句关于你工作或生活的话，录音 60 秒。
