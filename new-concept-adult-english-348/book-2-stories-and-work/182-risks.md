# Lesson 182: Risks / 风险

> **Book 2** · Unit 5: 项目进展 · 难度：★★☆☆☆

## 🎯 语法焦点

**连接词：because / so / although / however** — although / however / despite 让步转折

## 📖 课文

Yuki Tanaka identified the risk because the escalated the concern was documented the mitigation. Although it was monitored the metric, Yuki Tanaka tracked this risk. However, the April still needs work.

## 📐 本课核心

**规则：** because 原因 → I stayed late because the release was urgent.

**示范：** `The API was unstable, so we added a retry.` — API 不稳定，所以我们加了重试。

**避免：** ❌ `Although it rained, but I went out.` → ✅ `Although it rained, I went out.`（although 和 but 不能同时用）

## ✏️ 练习

1. 仿照示范句，用"风险"的真实场景写一句英语。
2. 把 `Although it rained, but I went out.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
