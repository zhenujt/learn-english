# Lesson 157: Superlatives / 最高级

> **Book 2** · Unit 2: 原因与比较 · 难度：★★☆☆☆

## 🎯 语法焦点

**比较级与最高级** — 比较级深化：less ... / as ... as / not as ... as

## 📖 课文

Alex Wang thinks approach is more reliable than scalable. The method version is the efficientest. It is less tool but more reliable. The team chose the most reliable option.

## 📐 本课核心

**规则：** 短词（1-2 音节）：加 -er / -est → faster, fastest。

**示范：** `Python is easier to read than C++.` — Python 比 C++ 更容易阅读。

**避免：** ❌ `She is more better.` → ✅ `She is better.`（better 本身就是比较级，不加 more）

## ✏️ 练习

1. 仿照示范句，用"最高级"的真实场景写一句英语。
2. 把 `She is more better.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
