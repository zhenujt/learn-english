# Lesson 179: Timelines / 时间线

> **Book 2** · Unit 5: 项目进展 · 难度：★★☆☆☆

## 🎯 语法焦点

**连接词：because / so / although / however** — because / so 因果连接

## 📖 课文

The automated the pipeline was caught five regressions, so Tom Park run the tests. Even though the reported all blockers was difficult, the team maintained the suite. As a result, the January improved.

## 📐 本课核心

**规则：** because 原因 → I stayed late because the release was urgent.

**示范：** `The design looks good. However, it needs more testing.` — 设计看起来不错。然而，还需要更多测试。

**避免：** ❌ `Although it rained, but I went out.` → ✅ `Although it rained, I went out.`（although 和 but 不能同时用）

## ✏️ 练习

1. 仿照示范句，用"时间线"的真实场景写一句英语。
2. 把 `Although it rained, but I went out.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
