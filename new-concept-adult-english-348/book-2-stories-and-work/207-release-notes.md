# Lesson 207: Release Notes / 发布通知

> **Book 2** · Unit 8: 产品与用户 · 难度：★★☆☆☆

## 🎯 语法焦点

**现在完成时** — 完成时 + 被动综合 ⟲（has been done） 🔄

## 📖 课文

Has Ravi Gupta fixes the memory leak before? Yes, Ravi Gupta has fixes the memory leak many times. The team has just stable. We haven't improves performance yet. Ravi Gupta has adds dark mode for undefined months.

## 📐 本课核心

**规则：** 结构：have/has + 过去分词。表示过去的动作与现在有关联（结果、经验、持续）。

**示范：** `She has never deployed to production alone.` — 她从未独自部署过生产环境。

**避免：** ❌ `Did you ever been to Japan?` → ✅ `Have you ever been to Japan?`（经验用现在完成时）
