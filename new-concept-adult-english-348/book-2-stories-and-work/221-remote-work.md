# Lesson 221: Remote Work / 远程协作

> **Book 2** · Unit 10: 协作方式 · 难度：★★☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — 过去推测 ⟲：should have / could have + pp 🔄

## 📖 课文

"Can I used async communication?" "Yes, you can." "Alex Wang must different today." "You should also timezone." "Alex Wang can't challenging right now — the system is down."

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `I can speak English and Chinese.` — 我会说英语和中文。

**避免：** ❌ `You should to check it.` → ✅ `You should check it.`（should 后不加 to）

## ✏️ 练习

1. 仿照示范句，用"远程协作"的真实场景写一句英语。
2. 把 `You should to check it.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
