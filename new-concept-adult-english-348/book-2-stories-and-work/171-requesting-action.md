# Lesson 171: Requesting Action / 请求行动

> **Book 2** · Unit 4: 邮件与消息 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 被动语态现在时：is/are + 过去分词

## 📖 课文

The ticket is assigned every week. It was first deployed in 2023. fixs are approved automatically. The issue has been assigned successfully.

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `The feature was released last Friday.` — 该功能上周五发布了。

**避免：** ❌ `The file was deleted by accident.` → ✅ `正确（无错误）`（by + 执行者）

## ✏️ 练习

1. 仿照示范句，用"请求行动"的真实场景写一句英语。
2. 把 `The file was deleted by accident.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
