# Lesson 175: Thank You Follow-up / 感谢跟进

> **Book 2** · Unit 4: 邮件与消息 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 主动 vs 被动选择 + by 短语 ⟲ 🔄

## 📖 课文

The issue is resolved every week. It was first implemented in 2023. suggestions are recognized automatically. The issue has been resolved successfully.

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `The issue has been fixed.` — 问题已经被修复了。

**避免：** ❌ `The report was write by Lin.` → ✅ `The report was written by Lin.`（被动语态要用过去分词）

## ✏️ 练习

1. 仿照示范句，用"感谢跟进"的真实场景写一句英语。
2. 把 `The report was write by Lin.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
