# Lesson 186: Asking Details / 询问细节

> **Book 2** · Unit 6: 支持与排错 · 难度：★★☆☆☆

## 🎯 语法焦点

**连接词：because / so / although / however** — 连接词综合 ⟲：复合句与复杂句 🔄

## 📖 课文

Mia Chen deadline because the feature scope was priority. Although it was decision, Mia Chen owner. However, the next step still needs work.

## 📐 本课核心

**规则：** because 原因 → I stayed late because the release was urgent.

**示范：** `I stayed late because the deadline was tomorrow.` — 我加班了因为截止日期是明天。

**避免：** ❌ `I was tired, however I continued.` → ✅ `I was tired; however, I continued.`（however 前用句号或分号）

## ✏️ 练习

1. 仿照示范句，用"询问细节"的真实场景写一句英语。
2. 把 `I was tired, however I continued.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
