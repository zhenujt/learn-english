# Lesson 180: Dependencies / 依赖关系

> **Book 2** · Unit 5: 项目进展 · 难度：★★☆☆☆

## 🎯 语法焦点

**连接词：because / so / although / however** — because / so 因果连接

## 📖 课文

Sara Li integrated the SDK because the resolved the conflict was updated the library. Although it was removed the legacy code, Sara Li managed dependencies. However, the last quarter still needs work.

## 📐 本课核心

**规则：** because 原因 → I stayed late because the release was urgent.

**示范：** `Even though I was tired, I reviewed the PR.` — 尽管我很累，我还是审查了 PR。

**避免：** ❌ `I was tired, however I continued.` → ✅ `I was tired; however, I continued.`（however 前用句号或分号）

## ✏️ 练习

1. 仿照示范句，用"依赖关系"的真实场景写一句英语。
2. 把 `I was tired, however I continued.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
