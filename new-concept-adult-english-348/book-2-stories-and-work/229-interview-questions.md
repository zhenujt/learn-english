# Lesson 229: Interview Questions / 面试问题

> **Book 2** · Unit 11: 职业成长 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 被动 + 情态 ⟲：should be done / must be fixed 🔄

## 📖 课文

The experience is relevant every week. It was first challenging in 2023. projects are measurable automatically. The issue has been relevant successfully.

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `Were the tests run before deployment?` — 部署前运行测试了吗？

**避免：** ❌ `The report was write by Lin.` → ✅ `The report was written by Lin.`（被动语态要用过去分词）

## ✏️ 练习

1. 仿照示范句，用"面试问题"的真实场景写一句英语。
2. 把 `The report was write by Lin.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
