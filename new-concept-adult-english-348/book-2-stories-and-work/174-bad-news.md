# Lesson 174: Bad News / 坏消息

> **Book 2** · Unit 4: 邮件与消息 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 被动语态过去时：was/were + 过去分词

## 📖 课文

The release was postponed by Yuki Tanaka's team. All features are removed before release. The budget is being cut right now. When was it postponed?

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `Were the tests run before deployment?` — 部署前运行测试了吗？

**避免：** ❌ `The file was deleted by accident.` → ✅ `正确（无错误）`（by + 执行者）

## ✏️ 练习

1. 仿照示范句，用"坏消息"的真实场景写一句英语。
2. 把 `The file was deleted by accident.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
