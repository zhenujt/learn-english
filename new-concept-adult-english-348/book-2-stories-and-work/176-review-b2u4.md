# Lesson 176: Review B2U4 / 复习

> **Book 2** · Unit 4: 邮件与消息 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 主动 vs 被动选择 + by 短语 ⟲ 🔄

## 📖 课文

The code was merged by Emma Liu's team. All tests are executed before release. The defect is being logged right now. When was it merged?

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `The feature was released last Friday.` — 该功能上周五发布了。

**避免：** ❌ `English is speak here.` → ✅ `English is spoken here.`（speak 的过去分词是 spoken）

## ✏️ 练习

1. 仿照示范句，用"复习"的真实场景写一句英语。
2. 把 `English is speak here.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
