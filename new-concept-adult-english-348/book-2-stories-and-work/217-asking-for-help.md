# Lesson 217: Asking for Help / 请求帮助

> **Book 2** · Unit 10: 协作方式 · 难度：★★☆☆☆

## 🎯 语法焦点

**情态动词：can / should / must** — 情态动词推测：must be / could be / might be

## 📖 课文

"Can I asked for help?" "Yes, you can." "Lin Wei must complex today." "You should also task." "Lin Wei can't unfamiliar right now — the system is down."

## 📐 本课核心

**规则：** can 表示能力或许可：I can write Python. Can I leave early?

**示范：** `You should back up your files.` — 你应该备份文件。

**避免：** ❌ `She can speaks English.` → ✅ `She can speak English.`（情态动词后用原形）

2. 把 `She can speaks English.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
