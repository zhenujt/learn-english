# Lesson 165: Client Requests / 客户请求

> **Book 2** · Unit 3: 生活问题解决 · 难度：★★☆☆☆

## 🎯 语法焦点

**第一条件句（真实条件）** — 条件句深化：unless / as long as / provided that

## 📖 课文

If the project passes, Alex Wang will renew the contract immediately. Unless someone negotiates, the fails will be delayed. If there is a problem, Alex Wang will lose the client.

## 📐 本课核心

**规则：** 结构：If + 一般现在时, will + 动词原形。表示真实可能发生的情况。

**示范：** `If she finishes early, she can help us.` — 如果她提前完成，可以帮我们。

**避免：** ❌ `Unless we won't fix it...` → ✅ `Unless we fix it...`（unless 本身含否定，不再加 not）

## ✏️ 练习

1. 仿照示范句，用"客户请求"的真实场景写一句英语。
2. 把 `Unless we won't fix it...` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
