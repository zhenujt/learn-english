# Lesson 177: Task Status / 任务状态

> **Book 2** · Unit 5: 项目进展 · 难度：★★☆☆☆

## 🎯 语法焦点

**被动语态** — 主动 vs 被动选择 + by 短语 ⟲ 🔄

## 📖 课文

The completed the backend is shipped the API every week. It was first updated the tests in 2023. refactored the modules are two weeks automatically. The issue has been shipped the API successfully.

## 📐 本课核心

**规则：** 结构：be + 过去分词。主语是动作的接受者。

**示范：** `All commits are reviewed before merging.` — 所有提交在合并前都会被审查。

**避免：** ❌ `The file was deleted by accident.` → ✅ `正确（无错误）`（by + 执行者）

## ✏️ 练习

1. 仿照示范句，用"任务状态"的真实场景写一句英语。
2. 把 `The file was deleted by accident.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
