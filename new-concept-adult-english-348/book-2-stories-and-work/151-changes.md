# Lesson 151: Changes / 变化

> **Book 2** · Unit 1: 经历与变化 · 难度：★★☆☆☆

## 🎯 语法焦点

**现在完成时** — for + 时间段 / since + 时间点

## 📖 课文

Has Ravi Gupta switched from Java to Go before? Yes, Ravi Gupta has switched from Java to Go many times. The team has just improved the CI pipeline. We haven't increased test coverage yet. Ravi Gupta has streamlined the process for automated the deployment months.

## 📐 本课核心

**规则：** 结构：have/has + 过去分词。表示过去的动作与现在有关联（结果、经验、持续）。

**示范：** `I have finished the code review.` — 我已经完成了代码审查。

**避免：** ❌ `I have finished it yesterday.` → ✅ `I finished it yesterday.`（有具体过去时间用一般过去时）

## ✏️ 练习

1. 仿照示范句，用"变化"的真实场景写一句英语。
2. 把 `I have finished it yesterday.` 改正，并说明原因。
3. 用本课语法焦点说 3 句关于你工作或生活的话，录音 30 秒。
