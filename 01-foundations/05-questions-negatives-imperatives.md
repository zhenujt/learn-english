# 05 Questions, Negatives, and Imperatives

## Definition and Core Formula

For ordinary verbs use `do/does/did + not + V` and `Do/Does/Did + S + V?`. With `be`, move `be` before the subject. Use `V` for an imperative and `Don't + V` for a negative command.

## Progressive Examples

1. `Do you live nearby?` 2. `Why did the pipeline fail?` 3. `The researchers asked why participants did not finish.`

## Common Mistakes

`Why you are late?` -> `Why are you late?` `He doesn't likes it` -> `He doesn't like it.`

## Self-check and Answers

Make a question: `The release failed.` Answer: `Did the release fail?` Write a command about secrets: `Don't commit secrets.`
