# 03 五大基本句型

## 定义

绝大多数英语句子可还原为五大句型。掌握它们，比记大量“万能句”更可靠。`be`、`seem`、`become` 等连系动词后接的是主语补语，不是宾语。

## 核心公式

1. `S + V`：`The service stopped.`
2. `S + V + O`：`We fixed the issue.`
3. `S + V + C`：`The issue is urgent.`（`C` 说明主语。）
4. `S + V + IO + DO`：`She sent me a link.`
5. `S + V + O + C`：`The team made the release stable.`（`C` 说明宾语。）

`IO` 是间接宾语（人），`DO` 是直接宾语（物/事）。第 4 句型也可写成 `S + V + DO + to/for + IO`：`She sent a link to me.`

## 递进例句

1. 生活口语：`My phone rang.` / `I called my friend.`
2. 工作沟通：`The manager gave the team a clear deadline.` / `The change made the page faster.`
3. 学术写作：`The results indicate that automated testing improves release reliability.`（此处 `that ...` 是宾语，后面会学。）

## 常见错误

| 易错写法 | 正确写法 | 原因 |
|---|---|---|
| `I explained him the problem.` | `I explained the problem to him.` | `explain` 不能直接接“人 + 物”。 |
| `The soup tastes deliciously.` | `The soup tastes delicious.` | 连系动词后用形容词说明主语。 |
| `We discussed about the plan.` | `We discussed the plan.` | `discuss` 是及物动词，不加 `about`。 |

## 造句方法

先写骨架：`The deployment failed.` 再按需要加时间、地点、原因：`The deployment failed last night because of a configuration error.` 骨架永远不丢。

## 自测

1. 给 `The dashboard looks clean.` 标注句型。
2. 改写：`She sent the report to us.` 改为双宾语句型。
3. 改错：`This update made users happily.`

## 答案

1. `S + V + C`。2. `She sent us the report.` 3. `This update made users happy.`
