# 08 Aspect, Passive Voice, and Agreement

## Definition and Core Formula

Use `be + V-ing` for an ongoing action, `have/has + past participle` for a past action connected to now, and `be + past participle` for passive voice. Make the verb agree with the real subject: `The list of changes is ready.`

## Progressive Examples

1. `I am cooking now; I have cooked dinner.` 2. `The affected users have been notified.` 3. `Data were collected and have been analyzed.`

## Common Mistakes

`I have finished it yesterday` -> `I finished it yesterday`. `The code is write` -> `The code is written`. `Each files are` -> `Each file is`.

## Self-check and Answers

Change `The team tests the API` to present perfect passive: `The API has been tested by the team.`
