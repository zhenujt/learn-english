# 08 完成、进行、被动与主谓一致

## 定义与核心公式

进行时强调过程：`be + V-ing`；现在完成时连接过去与现在：`have/has + V-ed`；被动语态强调承受者：`be + V-ed`。时态由 `be/have` 承担：`The bug was fixed.`、`The bug has been fixed.`

主谓一致以真正主语为准：`The list of changes is ready.`；`Each developer has ...`；`The developers have ...`。

## 递进例句

1. `I am cooking now. I have already cooked dinner.`
2. `We are investigating the outage. The affected users have been notified.`
3. `Data were collected over six months, and the results have been analyzed independently.`

## 常见错误

| 易错 | 正确 | 原因 |
|---|---|---|
| `I have finished it yesterday.` | `I finished it yesterday.` | 明确过去时间通常用一般过去。 |
| `The code is write by Ana.` | `The code is written by Ana.` | 被动用过去分词。 |
| `Each files are checked.` | `Each file is checked.` | `each + 单数名词 + 单数动词`。 |
