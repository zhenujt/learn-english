# 10 名词性从句

## 定义与核心公式

一个从句可以像名词一样作主语、宾语、表语或同位语。`that + 完整陈述句`，`whether/if + 完整陈述句`，`wh-word + 完整陈述句`。关键规则：从句内部使用陈述语序，不倒装：`I know what he needs.`

## 递进例句

1. `I think that you are right.`
2. `We need to know whether the API supports this format.`
3. `What the results demonstrate is that early testing reduces downstream costs.`

## 常见错误

| 易错 | 正确 | 原因 |
|---|---|---|
| `I know where is he.` | `I know where he is.` | 从句用陈述语序。 |
| `I don't know that whether ...` | `I don't know whether ...` | 不叠加引导词。 |
| `If it works is unclear.` | `Whether it works is unclear.` | 主语从句表示“是否”常用 `whether`。 |

## 自测与答案

1. 合并：`Where is the file? I do not know.` 2. 填 `that/whether/what`：`The problem is ___ the server is overloaded.` 3. 写一句含 `what` 从句的周报。答案：1. `I do not know where the file is.` 2. `that`。
