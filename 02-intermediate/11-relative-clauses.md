# 11 Relative Clauses

## Definition and Core Formula

Relative clauses modify a noun. Use `who` for people, `which/that` for things, `whose` for possession, and `where/when` for place/time. Non-defining clauses use commas and normally use `which`, not `that`.

## Progressive Examples

1. `The person who called is my manager.` 2. `This is the service that sends emails.` 3. `The experiment, which involved 300 people, was significant.`

## Common Mistakes

`The man which helped` -> `The man who helped`. `the developer which code` -> `the developer whose code`.

## Self-check and Answers

Combine: `I use a tool. It checks spelling.` Answer: `I use a tool that checks spelling.`
