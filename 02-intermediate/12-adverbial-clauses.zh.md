# 12 状语从句

## 定义与核心公式

状语从句说明时间、原因、条件、让步、目的、结果或方式。常用结构：`when/while/as + 时间`，`because/since + 原因`，`if/unless + 条件`，`although/though + 让步`，`so that + 目的`。条件或时间从句谈未来时，常用一般现在：`If it rains tomorrow, we will stay home.`

## 递进例句

1. `I will call you when I arrive home.`
2. `If the test passes, we will deploy the change; otherwise, we will roll it back.`
3. `Although the sample was limited, the findings are useful because they reveal a consistent pattern.`

## 常见错误

| 易错 | 正确 | 原因 |
|---|---|---|
| `If it will rain, ...` | `If it rains, ...` | `if` 条件从句通常不用 `will`。 |
| `Although ..., but ...` | `Although ...` 或 `..., but ...` | 不重复表达让步转折。 |
| `Because it was late, so ...` | `Because it was late, ...` | 不重复表达因果。 |

## 自测与答案

1. 用 `unless` 改写：`We will not ship it if the test does not pass.` 2. 填空：`___ the meeting ends, I will send the notes.` 3. 用 `although` 写一句项目状态。答案：1. `We will not ship it unless the test passes.` 2. `When/After`。
